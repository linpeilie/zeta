## T09 · macOS Keychain 凭据来源

- 状态：完成
- 日期：2026-08-12
- 变更：在 Claude Provider data 层新增可注入的只读 secure-storage source，以
  executable + 参数数组执行 `security find-generic-password`，固定 `runInShell: false`；
  不保留 stderr，stdout 设 1 MiB 上限，缺失、拒绝、超时、进程失败和损坏输出均折叠为
  `null`，再由 OAuth reader 回退 `.credentials.json`。
- service 对齐：默认使用 `Claude Code-credentials`；支持 custom/staging/local OAuth
  后缀；显式 `CLAUDE_CONFIG_DIR` 先按 Claude Code 源码做 NFC 规范化，再取 SHA-256 前八位。
  account 优先显式注入，其次 `USER`、`LOGNAME`，最后使用非身份 fallback。
- 凭据契约：瞬时快照增加不可变 `scopes`，继续拒绝缺 token、缺过期时间或已过期凭据；
  macOS Keychain 有效值优先，非 macOS 保持文件读取。Provider 为模型旧 fallback 与额度
  adapter 注入同一个 reader，但只有额度增强路径会触发读取。
