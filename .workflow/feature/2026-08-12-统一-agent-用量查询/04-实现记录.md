## T12 · 暂停：空历史展示语义冲突

- 进入生产注册前核对发现，T12 完成判据要求“Claude Code 无历史时不伪造 0”，但 T04
  已按当时确认的设计把 `sumAgentUsageTokens(empty)` 固定为全零，并注明这是“已支持但暂无
  记录”的既有展示语义。
- `ClaudeCodeTokenUsageSource` 在历史目录不存在时会正常返回 `available + empty records`；
  当前中立快照没有“从未发现历史”与“存在历史但查询时间窗内无记录”的区分。若直接注册，
  面板会显示 0，违反 T12 判据；若直接让空 records 返回 null，又会改变 Codex/Grok 以及
  “已有历史但今日无调用”当前显示 0 的语义。
- 该冲突无法在 Provider registry 中用 Claude id/kind 分支修补，否则会破坏本任务要建立的
  高内聚边界。合理修复需要用户确认是否扩展中立 token snapshot 的来源状态，或明确保留
  现有空记录显示 0 的语义并修订 T12 判据。
- 按用户止损要求，本步尚未修改生产 registry、UI 或共享契约，也未运行 T12 完成校验。
