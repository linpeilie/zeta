# Markdown 包改造决定

来源：2026-09-03 会话 UI 改造 WP-6。原记录状态：T1–T10、T14/T15 已完成；阶段五 P2 跳过。

## 保留本地包的原因

上游 `mixin_markdown_widget 0.3.1` 的公开扩展点不足以支持本项目的代码工具栏、语法、高亮和右键菜单。改名为 `zeta_markdown` 后在包内补充注入点，宿主提供主题和文案；默认值仍与上游一致。

包位于 `packages/`，可独立测试；不放入 `zeta_ui`，因为 Markdown 渲染有自己的解析、选择和图片加载依赖。它不依赖其他内部包。

现行定制及同步步骤只在 [UPSTREAM.md](../../../packages/zeta_markdown/UPSTREAM.md)维护，使用说明见[包 README](../../../packages/zeta_markdown/README.md)。旧接口草稿和逐步测试输出保留在 Git 历史。
