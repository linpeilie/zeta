# Provider 管理与用量贡献决定

来源：2026-09-04—2026-09-05 的 WP-D。实现已完成，验证见[记录](07-wpd-validation.md)。本页只保留仍被代码注释引用的设计决定。

## 管理与用量归属

各插件提供管理和用量贡献。中立契约在 api，协议实现和私有配置在各插件；宿主只提供模型目录、文本和不透明用量分区等窄端口，不向插件暴露 `StorageService`。

三类贡献必须属于同一 Provider，装配时校验唯一性和完备性。关闭后不能再次解析过期贡献。现行规则见[工程规范 §2.1](../../../docs/zh/architecture/engineering_standards.md#21-provider-插件包边界)。

### 3.6 安装指引例外

`agent_management_page.dart` 的 `_setupGuideAgentId` 只用于选择整张 Claude 安装指引卡。该卡包含厂商品牌说明，不能因为另一家声明了相同能力就显示给它。

因此保留这一处 id 条件。连接测试确认和额度详情增强仍按能力声明，不能借此例外新增业务身份分支。第二家需要安装指引时，应连同内容契约一起重新设计，并移除这一例外。

此决定不授权插件贡献任意 Widget，也不恢复旧过渡 import。规则已同步到工程规范，后续修改以那里为准。
