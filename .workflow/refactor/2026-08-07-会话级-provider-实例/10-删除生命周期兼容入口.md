# 删除生命周期兼容入口

日期：2026-08-09

## 目标

删除 Binding 重构后仍保留的旧控制器别名、原始 Provider 绑定入口、隐式 global scope、
权限状态改绑、用量仓库多 loader，以及 ViewModel 跨 thread 切换/恢复入口。

## 执行结果

- Workspace 在创建 thread entry 时一次性组合 thread summary、Binding 与 ViewModel；
  ViewModel 只保留 context 更新和当前固定 thread 的失败重试。
- 权限状态仅允许 draft 晋升，真实 thread 改绑 fail-closed。
- Registry acquire 必须显式传 scope；用量面板只通过 global runtime 读取 Provider 端口。
- 删除旧 UI 控制器别名、独立 idle reaper、turn pin 测试及对应兼容入口。
- 增加源码级架构守卫，防止旧符号和多 loader 路径回流。
