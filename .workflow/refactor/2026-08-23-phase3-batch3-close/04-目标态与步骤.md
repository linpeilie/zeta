# 第 3 批关批：目标态与步骤

## 目标结构

- Shell 永久创建一个 `ProjectThreadsSliceComposition`；store 是唯一列表 owner，既有
  `ProjectThreadsController` 只执行 Provider effect/query。
- MainApp 永久创建一个 `UsageStatisticsSliceComposition`；两个 store 分别拥有统计页
  与侧栏状态，Shell 只绑定选择持久化并消费 operations。
- usage 组合接收 app 注入的已启用 Provider 加载器：Provider Settings 切片存在时读其
  当前 store，否则直接宽容读取同一个配置仓库，不创建第二个 settings owner。
- Riverpod adapter 缺少组合根 override 时直接失败，不再把 null 当作 legacy 成功。
