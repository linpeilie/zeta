# 第 4 批关批：动机与止损线

## 动机

Workspace 与 IDE Session 的生产入口已经固定走纯 Dart 切片，但 Shell、`IdeHome` 与
`MainApp` 仍保留两个 feature flag、八个 Workspace 旧字段和一套 Session coordinator
false-path。继续保留会让同一业务事实仍有两种所有权解释，也阻塞目标架构要求的只读
根状态快照。

## 用户授权

用户于 2026-08-23 明确要求“执行关批和旧路径删除”，接受缩短原定至
2026-08-30 的观察余量，直接执行四步节奏第 4 步。第 1、2 批的独立观察窗口不受
本次授权影响。

## 止损线

- 任一既有 Workspace、恢复、保存、项目首页或 Workbench 布局断言需要改变；
- `ide_session.json` v4、codec、文件位置或持久化白名单需要改变；
- 根快照必须被生产 Widget watch，或必须复制会话正文、diff、日志、配置正文；
- Shell 必须新增 feature 可变状态才能完成关批。

命中任一项即停止扩展；关批后的回退使用提交 revert，不恢复双 owner 或双写。
