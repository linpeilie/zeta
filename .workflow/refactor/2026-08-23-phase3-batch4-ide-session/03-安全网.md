- reducer/store：restore lifecycle、初始完成、layout intent、save/saveNow typed effect；
- app runner：现有 coordinator 的 restore token、防抖与 pending snapshot 语义透传；
- 双路径 Widget：同一 `MainApp -> IdeHome` 在 flag false/true 下恢复、保存与慢恢复取消等价；
- 架构守卫：application slice 无 Flutter、Riverpod、`dart:io` 或 data import；
- schema 守卫：本轮 diff 不允许触碰 session domain codec/store 文件。
