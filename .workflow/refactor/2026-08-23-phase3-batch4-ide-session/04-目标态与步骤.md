# 目标态与步骤

## 目标结构

```text
MainApp
  -> IdeSessionSliceComposition（稳定创建，app 生命周期）
      -> IdeSessionSliceStore（restore/layout 运行态唯一 owner）
          -> pure reducer -> typed effects
              -> app runner -> 既有 IdeSessionPersistenceCoordinator
                  -> IdeSessionStore / v4 codec

IdeShellController
  -> IdeSessionSliceOperations（flag true）
  -> 只编排 restore result 到各 feature，并构建持久化白名单 projection
```

flag false 时新 store 保持 dormant，旧 coordinator/字段是唯一 owner；flag true 时旧
coordinator/字段保持初始值，只由新 store/runner 接收写入。
