# 现状测绘

## 当前结构与调用链

- `IdeShellController` 是 workspace 事实 owner：`_projects`、`_projectPath`、
  `_workspaceTree`、`_expandedDirectoryPaths`、`_currentFilePath`、
  `_selectedTreePath`、`_projectLastOpenedAtByPath`、`_isLoadingProject`。
- 打开项目：`IdeHome` → Shell → `Directory.exists` / `buildWorkspaceDirectoryChildren`
  → 写上述字段 → 文件索引 / Project Threads / Agent workspace / session save。
- 文件树：`FileTreePane` → Shell tap/expand → `WorkspaceNode.updateNode`，首次展开才读下一层。
- 恢复：`IdeSessionPersistenceCoordinator.restore` → sanitize 后由 Shell 重建已展开树并写字段。
- `@mention`：`WorkspaceFileIndexController` → 三个 callback/Listenable 参数 →
  `AgentThreadWorkspaceController` → `AgentConversationViewModel` → picker。

## 调用方清单

- 生产：`MainApp`、`IdeHome`、`FileTreePane`、`ProjectListPane`、`ProjectHomePage`、
  `AgentThreadWorkspaceController`、`AgentConversationViewModel`、mention picker、
  `ProjectThreadsSliceStore`、`IdeSessionPersistenceCoordinator`。
- 测试：workspace tree/index/indexer/query 测试；ide session domain/store/coordinator/restore
  Widget 测试；`ide_shell_controller_test`；Agent workspace 与 Composer mention 测试；

## 状态归属判定

- 4a 迁移：项目列表、活动项目、MRU、树、展开、选中、当前文件、加载态。
- 4b 迁移：restore operation/lifecycle、延迟保存 effect、Workbench layout 持久化入口。

- 派生缓存：文件 corpus 仍由 `WorkspaceFileIndexController` 按 root + generation 持有，
  不复制进 slice。
