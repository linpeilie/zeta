## 本轮补强

- 纯 reducer/store：加载 operation、迟到结果、惰性目录读取 effect、选择、移除、恢复、
  不可变集合和关闭语义；
- `WorkspaceFileIndexController`：去 Flutter 后 listener 增删与通知期间变更语义；
- `@mention` port：索引就绪优先、未就绪回退惰性树、通知透传；
- 双路径 Widget：同一真实 `MainApp → IdeHome → FileTreePane` 在 flag false/true 下打开、
  展开、选择与恢复等价；
- 架构守卫：workspace application 不再 import Flutter，移除已纯化的 domain 清单项。
