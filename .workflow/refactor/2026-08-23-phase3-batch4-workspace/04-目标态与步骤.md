# 目标态与步骤

## 目标结构

```text
IdeHome / Riverpod read-only mirror
  → WorkspaceSliceStore（4a 新路径唯一 workspace owner）
      → pure reducer → typed effects
          → app WorkspaceSliceRunner → tree reader / file index

Agent workspace → WorkspaceFileCorpusPort → active-root index/fallback tree

IdeShellController
  → 只编排 workspace 结果与 Project Threads / Agent workspace / session projection
```

4a flag 关闭时只写旧字段，新 store 保持 dormant；开启时只写 store，旧字段保持初始值，
不存在双写。4b 再把 `IdeSessionPersistenceCoordinator` 包进独立 effect runner。
