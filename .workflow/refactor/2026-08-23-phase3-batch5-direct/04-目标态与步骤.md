# 第 5 批直接迁移：目标态与步骤

## 目标态

- `DesktopAttentionSliceStore` 是未读与可见性的唯一 owner；纯 reducer 只产出 typed
  effect，runner 独占系统通知、indicator、设置订阅和 activation。
- `AgentConversationWorkspaceStore` 是 entry identity、选择、project home 与
  project→thread 映射的唯一 owner；Shell 只消费 workspace effect 协调 Project Threads、
  IDE Session 与通知定位。
- mode/model/skills 由一个 composer state owner 组合，作为 conversation slice 的内部
  状态引擎；ViewModel 不再分别创建可替换 owner。
- conversation slice 永久启用；resolver 首帧前绑定，所有 region 只读 Riverpod selector，
  不存在 ViewModel 直连 fallback。
