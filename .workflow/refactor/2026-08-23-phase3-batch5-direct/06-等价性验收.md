- Desktop Attention 的未读 identity、可见性、通知 id 只由 slice state 持有；runner
  独占系统副作用，payload 仍为 identity 白名单。

  Shell 不再维护镜像字段或 entry listener 表。

  明确失败。

  既有真实 `IdeHome` Widget 回归固定。

  用户可见文案与视觉均未改变。
