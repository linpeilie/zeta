# 现状测绘

## 当前结构

启动链为 `MainApp -> DefaultAgentProviderFactory -> ZetaPluginCatalog.compatibility ->
CompatibilityAgentProviderPlugin -> 单一 contribution -> kind switch -> native bundle`。
runtime registry 是唯一 factory caller 与 runtime owner，这一段保持不变。

core 的 `agent_provider_models.dart` 同时持有封闭 kind、三个内置 ID/default config 和展示名
归一化，是当前扩展面的集中目录。

## 影响面

- packages：`zeta_agent_core` provider models/capability resolver；
  `zeta_agent_providers` contribution、compatibility/default factory、static capability、
  permission migration、barrel、三个 native bundle。
- app：plugin catalog、`MainApp` 启动/关闭组合、Provider settings codec/store/composition。
- feature：Provider settings、conversation header/model source、management definition/reconcile、
  usage source registry、Provider icon fallback。
- tests：plugin catalog、provider catalog freeze、bundle architecture、config V1/V2、permission
  migration、native bundle、default factory、package contracts、相关 Widget/fixture imports。
- docs：Phase 1 账本与 §8.1、Phase 3 第 6 批、目标架构状态、core/providers barrel 注释。
