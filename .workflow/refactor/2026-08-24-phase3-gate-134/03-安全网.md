# 安全网

## 等价性约束

- settings 的 appearance 乐观持久化、general persist-first 与 Locale 冻结语义不变；
- Provider V1/V2 JSON、active/default 回退、模型目录与 management 能力行为不变；
- runtime registry、Binding、Timeline 和四种审批 owner 不变；
- root snapshot 仍只读、无监听、无正文，只把已唯一存在的四个节点改为必选。

## 新增门禁

- application/domain 不得 import `zeta_agent_providers`；
- application Flutter 例外清单必须为空；
- `zeta_agent_core` 源码与 manifest 均不得依赖 Flutter；
- 纯 Dart listenable 与 Flutter presentation adapter 分别有行为测试。

## 外部证据边界

自动化测试不能替代尚未执行的三平台构建、真实 CLI smoke、Profile 或长时间生产观察。
