## 11. 行为等价论证

本批的等价性风险集中在**一处**：把 4 重隐式副作用换成显式 `ZetaHostMode`。
逐条对照（映射关系写死在 `ZetaApplicationComposition.create` 与 `ZetaHostMode`）：

| 旧条件 | 旧结果 | 新条件 | 新结果 |
|---|---|---|---|
| 传了 session 回调 | session 走回调 | `ephemeral` + 注入 store | 走注入 store |
| 传了回调 | 持久化全内存 | `ephemeral` | `usesFilePersistence == false` → 全内存 |
| 传了回调 | CLI 探测被 stub 顶掉 | `!hostMode.allowsLocalCliAccess` | 同 stub |
| 传了回调 | 用量自动刷新关闭 | `!hostMode.allowsLocalCliAccess` | 同关闭 |
| 无回调 + `dataPaths != null` | 文件持久化 | `local` + `dataPaths != null` | 文件持久化 |
| 无回调 + `dataPaths == null` | 内存 | `local` + `dataPaths == null` | 内存 |

其余 `??` 分支（显式注入优先）逐字搬迁，判断顺序未变。

**证据**：`main_app_host_persistence_characterization_test.dart` 的 5 条断言
在改动前后**完全相同且都通过**——这正是它先于结构改动单独提交的目的。
