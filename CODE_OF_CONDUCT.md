# 行为准则 / Code of Conduct

## 参与讨论

尊重每位参与者，不因身份、背景、能力或经验而骚扰、排斥他人。

- 对代码、问题和证据提出意见，不贬低提交者。
- 说明分歧的具体原因，接受必要的修正。
- 不发布辱骂、威胁、歧视或性骚扰内容。
- 不在未经同意的情况下公开他人的住址、邮箱或其他私人信息。

这些要求适用于 Issue、PR、讨论、提交信息，以及代表项目参与的公开活动。明确要求修改代码属于正常评审，人身攻击不属于。

## 处理违规

使用 GitHub 的举报功能报告骚扰或其他违规内容。需要维护者介入时，可在相关讨论中联系 [@linpeilie](https://github.com/linpeilie)，不要公开举报人的私人信息或重复传播有害内容。

维护者可以移除违规内容、限制讨论，或对重复及严重违规者限制参与。处理报告时应保护举报人的隐私。

## Participation

Respect participants regardless of identity, background, ability or experience.

- Critique code, issues and evidence rather than the contributor.
- Explain disagreements and accept necessary corrections.
- Do not post insults, threats, discrimination or sexual harassment.
- Do not disclose someone's address, email or other private information without consent.

These rules apply to issues, PRs, discussions, commit messages and public activity representing the project. Direct requests for code changes are normal review; personal attacks are not.

## Handling violations

Use GitHub's reporting feature for harassment or other violations. Contact [@linpeilie](https://github.com/linpeilie) in the relevant discussion when maintainer action is needed, without disclosing private information or repeating harmful material.

Maintainers may remove content, restrict discussions or limit participation for repeated or serious violations. Reports should be handled with respect for the reporter's privacy.
