# Settings

Open settings with the gear button in the title bar. The sections are General, Appearance and Agents.

## Sending messages

| Choice | Send | New line |
| --- | --- | --- |
| Enter to send (default) | Enter | Shift + Enter |
| Cmd + Enter to send (Mac) | Cmd + Enter | Enter |
| Ctrl + Enter to send (Windows / Linux) | Ctrl + Enter | Enter |

The latter two choices can help when you often write several lines.

## Notifications

System notifications is the main switch. Task ended and Needs confirmation control the two reminder categories. Your system must also allow Zeta notifications. See [Notifications](notifications.md).

## Language

Choose English or Simplified Chinese, then restart Zeta to apply it. Existing conversations, model names and filenames are not translated.

A new installation uses Chinese when the system's preferred language is Simplified Chinese; Traditional Chinese and other languages use English. Earlier installations retain their Chinese setting.

## Theme and fonts

Choose System, Light or Dark for the theme.

The interface font is for ordinary text; the code font is for code and commands. Both default to system fonts, and you can select other installed fonts.

Interface size ranges from 10–20 and code size from 10–24. Changes apply immediately. If a selected font is unavailable, Zeta uses the default and shows a notice.
