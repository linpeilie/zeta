# Interface Tour

With a project open, Zeta has three main areas.

## Left: projects and conversations

Select a project to switch to it, then expand it to see past conversations. Open a conversation to read it or continue talking.

The button beside a project starts a new conversation. Its menu offers refresh, opening the folder in your system's file manager, and removing the project from the list. Removing a project does not delete its files.

Conversation menus may offer renaming, archiving, branching or deletion, depending on the assistant. **Delete conversation** and **Remove from Zeta list** have different effects. Read the confirmation: the latter keeps the assistant's own history.

Expand the usage summary at the bottom of the sidebar to see the selected assistant's plan and today's usage.

## Middle: the conversation

Messages, replies and operation records appear in time order above the input box. Requests waiting for your approval or answer stay above that box.

The top of the conversation shows the project and conversation names. “Context” offers conversation information, usage and detailed records for troubleshooting. Check for private information before sharing these records.

See [Conversations and the Timeline](conversations.md) for controls.

## Right: files

Expand folders and select files in the current project. Selecting a file tells the assistant which file you mean; ask it to read the file in your message.

Zeta does not have a file editor. Changes made by the assistant can appear in the conversation, to the extent that the assistant reports them.

Some tool folders are hidden, including `.git`, `.dart_tool`, `.idea`, `.vscode`, `build` and `node_modules`.

## Top controls

The menu opens projects and exits the app. Other buttons return to the conversation, open usage or settings, and hide the sidebars. The file sidebar is unavailable on settings and usage pages.

Drag between columns to resize them. In a narrow window, sidebars open over the conversation and can be closed to continue reading.

The project list, column widths and some expanded items are saved. Reopening Zeta returns to the last project, not the last conversation; clicking a notification still opens that conversation. Switching to settings, usage or another conversation and back preserves your draft and reading position. Unsent drafts are not guaranteed to survive closing the app.

Adjust fonts, text size and the light or dark theme in [Settings](settings.md).
