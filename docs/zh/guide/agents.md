# 连接 AI 助手

在「设置 → Agent 管理」中检测和管理助手。界面中的 Agent 或 Provider 指连接的 AI 助手；Claude Code 在部分位置简称 Claude。

## 支持的功能

Codex、Grok 和 Claude Code 都支持新建对话、继续历史对话、取消任务、权限确认、回答问题和选择模型。其他功能有以下区别：

| 功能 | Codex | Grok | Claude Code |
| --- | :---: | :---: | :---: |
| 任务进行时补充消息 | ✓ | — | — |
| 重命名会话 | ✓ | ✓ | — |
| 归档或创建分支 | ✓ | — | — |
| 删除助手保存的会话 | ✓ | ✓ | — |
| 仅从 Zeta 列表移除 | — | — | ✓ |
| 整理长对话（Compact） | ✓ | — | ✓ |
| 用 `@` 引用文件 | ✓ | ✓ | — |
| 选择 Skill 任务说明 | ✓ | ✓ | — |
| 附加图片 | ✓ | — | — |
| 计划模式 | ✓ | ✓ | ✓ |
| 独立的「接受计划」卡片 | — | ✓ | ✓ |
| Fast 选项 | ✓ | — | — |

连接后，实际选项还取决于助手版本、模型和账号。未支持的功能不会显示入口。计划的使用方法见[审批、提问与计划](approvals.md)。

## 检测与连接

1. 点击「自动检测 Agent」。
2. 选择要使用的助手，查看是否已安装、已登录，以及版本是否可用。
3. 按提示处理问题，再点「测试连接」。

连接测试不发送聊天内容，也不要求模型回答；它用于检查 Zeta 能否连接助手。助手本身仍可能联网、检查登录或更新自己的文件。若界面提示需先确认，请阅读说明后操作。

如果终端里能用、Zeta 却找不到，先完全退出 Zeta 再打开。仍失败时，核对管理页显示的程序位置；常见原因是安装后应用没有获取新的程序位置，或电脑上装了多个版本。

禁用助手前请阅读确认提示，正在进行的任务可能会被停止。已有对话可继续查看，重新启用后再尝试发送。

## 查看模型

「模型」页列出助手当前提供的模型，并显示更新时间。加载失败时先检查登录和连接。旧列表被保留时，界面会说明它不是刚刚读取的结果。

## 修改配置

「配置」页用于编辑助手自己的设置文件，适合已经了解这些设置的人。

敏感内容默认遮挡。显示完整内容后才能编辑；保存前会检查格式和外部修改，并备份原配置。如果提示文件已被其他程序修改，先核对两边内容再决定。

保存后是否需要重启助手，以页面提示为准。不要把包含密码或密钥的配置贴到公开问题报告中。

## 查看日志

「查看运行日志」提供筛选、搜索和复制。常见密码、密钥会被遮挡，但仍应检查项目路径、文件名和账号信息，再决定是否分享。

## Claude Code 的额度详情开关

「额度详情增强」用于读取更详细的套餐用量，例如五小时和一周内的用量。关闭它仍可使用对话、模型列表和套餐名称。

无论此开关是否开启，为保持 Claude Code 登录，Zeta 都可能在连接和发送新请求前更新助手已有的登录信息。不会在 Zeta 数据目录另存凭据副本。续期失败时，请按界面提示重新登录。见[数据与隐私](data-and-privacy.md#助手的数据与登录)。

## 版本要求

以下是本项目记录的兼容范围，不代表各助手的最新版本：

- Codex：最低兼容版本为 0.142.5；从指定历史位置创建分支需要 0.144.5。
- Grok：多会话兼容基线为 0.2.119。
- Claude Code：项目曾验证 2.1.224、2.1.227、2.1.228 的不同功能；这不是最低版本或所有后续版本的兼容承诺。

发现版本不兼容时，按检测页提示处理。其他问题见[故障排查](troubleshooting.md#助手连接)。
