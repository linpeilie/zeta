# 审批、提问与计划

Zeta 的默认立场是：**不替你同意任何事**。AI 想执行命令、写文件或者访问网络，都要先问你。这篇文档说明它会怎么问、你有哪些选项、以及计划模式怎么用。

Zeta 里有四种需要你参与的情形，语义完全分开，不会混为一谈：

1. 权限审批——AI 要做一件有副作用的事
2. AI 提问——AI 需要你提供信息才能继续
3. 计划审批——AI 拿出一份方案，问你认不认
4. 计划执行确认——方案通过了，问你用什么权限开始干

不管哪一种，卡片都固定出现在输入框上方，不会被新消息挤走。

## 权限审批

### 卡片上有什么

一张权限卡片会写清楚三件事：**是什么类型的操作**（执行命令 / 应用文件变更 / 授予权限 / 请求确认）、**具体要做什么**（哪条命令、哪个文件、什么改动），以及**是谁在请求**。

### 你的选项

| 选项 | 效果 |
| --- | --- |
| 允许 | 只放行这一次。 |
| 拒绝 | 不允许。AI 会知道被拒绝了，通常会换个做法或者问你。 |
| 本会话允许 | 这个会话里，同类操作以后不再问你。会话结束就失效。 |
| 始终允许 | 记住这个决定，之后同类操作不再问。 |

有些请求还会出现「覆盖守护」——用于放行被助手自身安全策略拦下的操作。这个选项只在助手明确提供时出现。

### 卡片自己消失了

响应过的请求不会重复出现，这是有意的。如果一张卡片你没点就消失了，通常是这几种情况：

- 请求超时了
- 你在别处（比如助手的命令行界面）回应了同一个请求
- 助手进程退出了

### 权限模式

除了逐次审批，你还可以给整个会话设定一个基调，也就是输入框旁边的**权限模式**。每个助手提供的模式不一样：

- **Codex**：Read only（只读）/ Workspace write（可写工作区）/ Full access（完全访问）。如果你在 Codex 配置里定义了自己的权限档案，它们也会出现在这个列表里。
- **Claude Code**：Ask（每个高风险工具都问）/ Accept edits（自动允许编辑类工具，其他仍问）/ Plan（只读并产出计划）/ Bypass permissions（跳过权限检查，高风险）。
- **Grok**：Ask / Auto / Always approve。

切换权限模式什么时候生效，取决于助手：有的下一回合生效，有的下次发送时生效，有的要等新会话。界面上会写明。回合正在跑的时候不能切换，Zeta 会提示你等这一回合结束。

选了宽松的模式意味着你主动放弃了逐次确认，Zeta 会照办，但不会替你做这个决定。

## AI 提问

AI 有时需要你提供信息才能继续，比如让你在几个方案里挑一个。这时会出现提问卡片，和权限审批分开显示。

提问可能有多道。卡片上会显示「第几题 / 共几题」，可以用上一题、下一题来回翻。每道题：

- 选项可能是单选，也可能是多选（多选时卡片会标明）
- 可以选「其他」自己写答案
- 可以跳过某一题
- 全部答完后点「提交答案」一次性回给 AI

如果一个提问请求里没有任何可回答的问题，Zeta 会直接告诉你，不会让你对着空卡片发呆。

## 计划模式

想让 AI 先想清楚再动手，用计划模式。

### 进入计划模式

在输入框里输入 `/`，选择 `Plan`。输入框上会出现一个「Plan」标记，表明下一回合是只读规划——**AI 在这个模式下不能改文件**。

也可以在权限模式里直接选 Plan（Claude Code 支持这样用）。

### 读计划

计划产出后会出现在对话区的计划面板里，逐条列出步骤，每步标着状态（待处理 / 进行中 / 已完成）。执行过程中这个面板会实时更新进度，也可以折叠起来。

### 三个出口

看完计划，你有三个选择：

- **接受计划**——认可这个方案。注意：接受计划**只是确认方案本身**，并不等于授权里面提到的命令和文件操作。那些仍然会一条条单独请求。（Codex 没有这一步，计划回合结束后直接进入下面的执行确认。）
- **修改**——在输入框里补充或修改要求，让 AI 改计划。可以来回改几轮。
- **放弃**——不采用，回到普通对话。

### 执行确认

接受计划之后，还有一步：Zeta 会问你**用什么权限执行**。

这一步是刻意分开的。计划审批和实际执行是两件事，接受方案不会预先授权任何命令、文件写入或网络访问。执行确认卡片上会显示：

- 计划有几个步骤
- 这次执行使用哪个权限模式。默认沿用你进入计划前的设置；如果那个设置已经失效，会回落到助手的保守默认值，卡片上会标注这是「保守默认」。
- 你也可以只为这一次执行改选一个权限模式，标记为「仅本次」，不会被保存下来影响以后。

确认后，Zeta 会**新开一个普通回合**来执行计划，而不是在原来那个回合里继续。所以执行过程中该问的权限还是会问。

如果当前没有可用的权限选项，Zeta 会要求你先选一个再执行，不会挑一个默认值蒙混过关。

## 一条底线

不管你怎么操作，有一件事 Zeta 从不做：**在你没有明确表示同意的情况下，替你授权任何操作**。计划审批不预授权执行，执行确认不预授权具体命令，宽松的权限模式是你自己选的、界面上写明了它意味着什么。
