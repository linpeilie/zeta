# 审批、提问与计划

助手需要你回应时，卡片会出现在输入框上方。先看清它是在请求操作权限、询问信息，还是请你确认计划。

## 确认操作

权限卡片用于请求运行命令、修改文件或其他操作。卡片会显示助手提供的操作内容。选择「允许」前，确认涉及的文件和影响符合你的任务。

「拒绝」表示不允许这项操作。有些助手还提供在本会话内记住决定、长期记住决定等选项；只在理解其影响范围时使用。具体选项及范围以卡片说明为准。

是否每次询问，取决于你选的权限模式。允许自动编辑或完全访问后，部分操作可能直接执行。Zeta 不会因为你接受了计划而额外放宽权限。

请求已结束、超时或助手断开时，卡片可能消失。查看对话记录确认当前状态，不要把消失本身当作已获批准。

## 选择权限模式

输入框附近的权限选项决定助手在当前任务中能做什么。

| 常见选项 | 含义 |
| --- | --- |
| Read only / Plan | 用于查看和规划，限制修改；具体可执行操作由助手决定 |
| Workspace write / Accept edits | 允许一定范围的文件修改；其他操作是否询问取决于助手 |
| Full access / Bypass permissions / Always approve | 放宽或跳过部分确认，使用前查看该选项的说明 |

各助手的模式不完全相同，不能只凭名称认为它们有相同权限。改动何时生效，以界面提示为准。

## 回答问题

提问卡片用于补充信息，例如选择方案或说明偏好。按题目选择答案，也可以使用提供的自由输入入口。多道题可以来回查看，完成后提交。

如果选择跳过，助手可能依据已有信息继续，也可能再次提问。回答问题本身不授权命令或文件修改。

## 先写计划

希望先看方案时，在 `/` 菜单选择 `Plan`；Claude Code 可从权限选项选择 Plan。然后说明你想解决的问题和限制。

计划出现后，可以继续补充要求，让助手修改方案。某些助手会显示「接受计划」卡片；Codex 没有单独的这一步。

接受计划表示同意方案。后续仍按当前有效权限执行，需要审批的操作仍会询问。

## 开始执行计划

出现执行确认卡片时，检查计划和执行权限，再选择开始。卡片通常沿用进入计划前仍有效的权限设置；原设置不能继续使用时，会采用助手提供的保守选项，或请你重新选择。

标为「仅本次」的选择只用于这次执行。开始后会产生一个新的执行回合。你也可以选择继续规划，暂不执行。

后台有卡片等待回应时，可通过[桌面通知](notifications.md)回到对应会话。
