# 对话与时间线

一条会话属于一个项目和一个 AI 助手，可以在以后继续。你发出请求，助手完成这次任务，算一个回合。

## 阅读记录

对话区会显示你的消息、助手的回复，以及助手报告的操作。点击操作条目可查看命令、涉及的文件或返回结果。连续的同类操作可能收在同一组中。

如果助手提供思考说明，可以展开阅读。任务结束后，有文件修改记录时会显示「本回合改动」，展开后对照修改前后的内容。没有详细记录不代表没有改动，请同时检查项目文件。

每个回合会标明正在进行、已完成、失败或已中断。你向上阅读时，新内容不会把页面拉回底部；点击新内容提示可回到最新位置。右侧的对话导航可以跳到指定回合。

## 输入消息

默认 Enter 发送，Shift + Enter 换行；可在设置中更改。

| 输入方式 | 用途 |
| --- | --- |
| `@` | 按名称选择要引用的项目文件 |
| `$` | 选择一项 Skill，也就是助手预先准备的一组任务说明 |
| `/` | 打开命令菜单，例如计划或整理长对话 |
| 粘贴图片或附加图片 | 把截图等图片交给助手查看 |

这些入口只在所选助手支持时出现。菜单可用上下方向键选择、Enter 确认、Esc 关闭。

## 模型与思考程度

输入框旁可以选择模型。有相应选项时，也可以调整思考程度或启用 Fast。更换选项何时生效，以界面提示为准；不会改变已经完成的回合。

如果选择需要确认，先读提示再继续。保存失败时，原选择会保留，可稍后重试。

## 取消任务

任务进行时点击「取消回合」。取消请求发出后，查看回合状态确认是否已停止。

**取消不会撤销已经执行的命令或文件修改。** 需要恢复文件时，请使用项目的备份或版本管理工具。

## 编辑消息与创建分支

支持此功能的助手会提供「编辑消息」「创建分支并重试」或「分叉」等选项。它们保留原对话，并从选定位置开始另一条对话。

新分支只改变对话记录。原任务已经修改的文件仍然保持修改后的状态。

## 整理长对话

助手一次能参考的对话内容有限。菜单里的 `Compact` 会让助手整理已有内容，为后续对话腾出空间。整理后可能不再保留所有细节；有重要要求时可以在下一条消息里重申。

有些助手会自动整理，并在对话里留下提示。

## 只能看，不能发送

检查「设置 → Agent 管理」中，这条会话使用的助手是否被禁用。重新启用后再尝试发送。若仍不可用，查看[故障排查](troubleshooting.md)。
