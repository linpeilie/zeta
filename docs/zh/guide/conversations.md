# 对话与时间线

时间线是 Zeta 的核心。AI 在你电脑上做的每一步都摊在这条线上，按发生顺序排列，随时可以往回翻。这篇文档说明时间线上有什么、你能对它做什么。

## 一次对话的结构

一条**会话**是你和 AI 的一次完整对话，可以跨天继续。会话属于某个项目，也属于某个 AI 助手——会话一旦用 Codex 开始，就一直是 Codex 的。

会话由若干**回合**组成。你发一条消息，AI 干完活给出答复，这就是一个回合。回合有四种结局：

| 状态 | 含义 |
| --- | --- |
| 生成中 | AI 正在工作 |
| 已完成 | 正常结束 |
| 失败 | 出错了，时间线上会写明原因和建议 |
| 已中断 | 被你取消，或者助手进程退出了 |

时间线上回合与回合之间用一条细线和大片留白分开，很容易看出边界。

## 时间线上会出现什么

**你的消息**——原样显示，包括你引用的文件和插入的 Skill。

**AI 的回复**——按 Markdown 渲染，代码块带语法高亮。

**思考过程**——助手在给出答复前的推演，折叠显示，点开可读。不是所有助手都提供这个。

**工具调用**——AI 每次读文件、改文件、跑命令、搜索、抓网页，都会作为一个条目出现，标着动作类型（读取 / 编辑 / 删除 / 移动 / 搜索 / 执行 / 获取）和当前状态（待执行 / 进行中 / 已完成 / 失败 / 已取消）。点开能看到它到底读了哪个文件、跑了哪条命令、拿到了什么结果。

连续的同类操作会合并显示：连着跑几条命令会归成一个「命令组」，连着改几个文件会归成一个「文件编辑组」，避免时间线被刷屏。

**本回合改动**——这一回合结束后，如果 AI 动了文件，时间线上会出现一张汇总，写明改了几个文件、各是新建 / 修改 / 删除 / 移动，展开能逐个看到改动内容：

- 统一差异（就是常见的 diff 视图，新增行和删除行分色显示）
- 替换片段（替换前 / 替换后对照）
- 写入内容（新建文件时的完整内容）

改动量较大时这些区块可以单独滚动，也支持键盘上下翻页。

**其他事件**——AI 提问、权限请求、计划审批、上下文被压缩、子任务活动、模型被改道、等待重试等，都会作为独立条目出现在时间线上，不会藏起来。

## 阅读长对话

对话变长以后：

- 右侧有一条**对话导航**，标出每个回合的序号和状态，点一下直接跳过去。
- 你往上翻的时候，新内容不会强行把你拽到底部。底部会出现一个「有新内容」的提示，点它才回到最新。
- 对话再长滚动也不会变卡，几百个回合同样跟手。

## 输入框

输入框支持几种快捷输入，光标位置输入触发符即可，用上下键选择、回车确认：

| 输入 | 作用 |
| --- | --- |
| `@` | 引用项目里的文件。输入文件名筛选，选中后插入成一个可点的引用块。 |
| `$` | 插入一个 Skill——助手预置的一套可复用指令。 |
| `/` | 打开命令菜单：`Plan`（进入计划模式）和 `Compact`（压缩当前会话的上下文），下面接着列出可用的 Skill。 |

还可以直接把截图粘贴进输入框，或者用「附加图片」选择本地图片。

这几项都取决于你用的助手支持到什么程度。不支持的入口不会出现在界面上——不会给你一个点了没反应的按钮。

发送快捷键默认是 Enter，可以在设置里改成 Cmd + Enter 或 Ctrl + Enter；改了之后 Enter 变成换行。

## 选模型和思考程度

输入框附近有模型选择器。点开可以选模型；如果这个模型支持调节思考程度（低 / 中 / 高之类），下面会出现对应的选项。有些模型还提供 Fast 档位，开启后响应更快，但和某些思考程度互斥——遇到冲突时 Zeta 会让你二选一，不会默默改掉你的设置。

模型和思考程度的改动**从下一回合开始生效**，不会打断正在跑的这一回合。界面上会明确写「配置将在下一回合生效」。

如果你选的模型不再可用，Zeta 会切到一个可用的模型并告诉你切到了哪个。

## 中途叫停

AI 正在工作时，发送按钮会变成「取消回合」。点它就停。已经做出的改动不会自动回滚——文件已经写了就是写了，Zeta 不替你撤销磁盘上的操作。

## 改写历史：编辑消息与分叉

想换个说法重来一次，把鼠标移到你之前发的某条消息上，点「编辑消息」。改完发送时，Zeta **不会**覆盖原来的对话，而是从那条消息之前的位置**新建一条分支会话**，原会话完整保留。

同样地，某个回合失败了，可以用「创建分支并重试」从那里重新开始。

有一点必须说清楚：**分叉只影响对话记录，不影响你的文件**。AI 之前写进磁盘的改动仍然在那儿，Zeta 不会回滚工作区。要撤销文件改动，用你自己的版本控制工具。

## 压缩上下文

AI 一次能记住的内容是有上限的（也就是上下文窗口）。对话很长时这个额度会被占满。输入 `/` 选 `Compact` 可以让助手压缩当前会话的上下文，腾出空间继续聊。压缩发生后，时间线上会出现一条「上下文已压缩」的记录，你知道这件事发生过。

有的助手也会在窗口快满时自己触发压缩，同样会在时间线上留痕。

## 只读会话

如果一条会话显示「此会话为只读模式」、输入框不见了，说明它所属的 AI 助手在设置里被禁用了。历史仍然可以完整翻阅，只是不能再发消息。到「设置 → Agent 管理」重新启用即可。

## 看原始数据

对话区顶部的「上下文」面板里有一个「原始消息」视图，显示 Zeta 与助手之间未经加工的往来内容。可以拖选，也可以用「复制原文」按钮整段复制。排查问题、或者你想确认界面上的呈现有没有丢东西时，看这里。
