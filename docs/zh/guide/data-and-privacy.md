# 数据与隐私

Zeta 在本机运行，没有自己的云端对话服务或遥测。**这不表示你的消息和代码一定留在电脑上：连接的 AI 助手可能把它们发送给模型服务。**

## 哪些内容会交给助手

发送消息时，助手会收到你的消息、附加图片、文件引用，以及当前项目和选中文件的位置。助手可以按你选择的权限读取文件，并把需要的内容用于回答。

是否联网、发送哪些内容、在服务端保留多久，取决于所用助手、账号和设置。处理私人或工作资料前，请确认这些设置符合你的要求。

## Zeta 自己保存什么

Zeta 在系统「文档」目录中的 `.zeta` 文件夹保存设置、项目列表、使用统计、日志和模型列表等数据。常见位置如下；如果文档目录被重定向或同步，实际位置也会随之改变。

| 系统 | 常见位置 |
| --- | --- |
| macOS | `~/Documents/.zeta/` |
| Windows | `%USERPROFILE%\Documents\.zeta\` |
| Linux | 用户文档目录中的 `.zeta` 文件夹 |

这些文件没有单独加密。能访问该目录的人可能看到项目路径、会话名称、模型选择和使用量。

Zeta 的统计和日志不保存消息正文、助手回复、工具输出或登录凭据。完整对话仍可能由助手保存在它自己的历史记录中。

## 助手的数据与登录

Zeta 会读取所连接助手的配置、账号状态、对话历史和日志，用于连接、恢复对话、排查问题和统计使用量。

以下操作会改变助手自己的数据：

- 在配置页点击保存，会更新助手配置，并备份原配置。
- 使用助手支持的重命名、归档或删除功能，会相应改变助手保存的会话。
- 使用 Claude Code 时，Zeta 可能更新它已有的登录信息，以维持登录。更新失败时可能需要重新登录。

「从 Zeta 列表移除」只隐藏列表记录，不删除助手的历史文件。Claude Code 的「额度详情增强」只控制额外的用量查询，关闭它不会停止维持登录所需的检查。

## 日志与通知

日志用于记录运行状态和问题，常见密码、密钥会被遮挡。分享日志前，仍请检查是否包含私人路径、文件名或账号信息。日志目前需手动清理。

系统通知只显示事件类别和简短项目名称，不显示消息、命令或错误正文。项目名称本身也可能属于私人信息；不希望它出现在通知中心时，可关闭[系统通知](notifications.md)。

## 清理与重置

**先退出 Zeta，再备份要清理的文件。** 以下路径都相对于上述 `.zeta` 文件夹。

| 想清理什么 | 对应位置 | 影响 |
| --- | --- | --- |
| 模型列表缓存 | `cache/` | 下次使用时重新读取 |
| 使用统计缓存 | `state/usage_statistics_index.json` | 从仍存在的助手历史重新统计 |
| Zeta 记录的每次对话设置 | `state/session/` | 可能失去历史记录中未提供的模型等补充信息 |
| 打开过的项目与布局 | `state/ide_session.json` | 需要重新打开项目和调整布局 |
| 外观、语言和快捷键 | `config/appearance.json`、`config/general.json` | 恢复默认设置 |
| 助手启用状态和偏好 | `config/providers.json` | 需要重新选择助手和偏好 |
| Claude 的列表隐藏及会话决定 | `state/claude_code/` | 隐藏记录可能重新出现，已记住的会话决定被清除 |
| 应用日志 | `logs/` | 失去对应的排查记录 |
| Zeta 全部本地设置和记录 | 整个 `.zeta` 文件夹 | 重置以上内容 |

这些操作不删除项目文件，也不删除助手自己的配置和完整历史。删除缓存后只能从仍然存在的数据重建，已被删除的助手历史无法通过重建找回。

安全问题请按[安全策略](../../../SECURITY.md)中的方式报告，避免公开私人内容。
