# 安装与上手

第一次使用需要准备一个 AI 助手，再安装 Zeta。

## 准备助手

Zeta 支持 Codex、Grok 和 Claude Code。请按所选助手的官方说明安装并登录，确认它能独立使用。Zeta 不提供模型账号，也不代付模型费用。

如果你还没用过这类工具，请先完成助手自己的入门步骤，再连接 Zeta。版本说明见[连接 AI 助手](agents.md#版本要求)。

## 安装 Zeta

从 [Releases](https://github.com/linpeilie/zeta/releases) 下载对应系统的安装包，以该版本列出的系统要求和文件为准。

| 电脑 | 选择 |
| --- | --- |
| Mac | `.dmg`；不确定芯片类型时选名称含 `universal` 的包 |
| Windows 64 位 | 名称以 `setup.exe` 结尾的安装包；安装结束后从开始菜单打开 Zeta |
| Linux 64 位 | 适合所用系统的 `.deb`、`.rpm` 或 `.AppImage` |

也可以选免安装压缩包，解压后运行 Zeta。下载页中的 `.sha256` 文件用于检查下载是否完整。

当前安装包没有开发者签名，首次打开可能出现系统提示。确认文件来自本项目的发布页后，再按系统提示允许打开；如果出现文件损坏或安全软件报警，不要把它当成同一种提示，参见[故障排查](troubleshooting.md#安装与启动)。

## 打开项目

1. 启动 Zeta。
2. 点击「打开项目文件夹」，或使用「文件 → 打开项目」。
3. 选择要交给助手处理的本地文件夹。

左栏列出项目与历史对话，中间是对话区，右栏列出文件。右栏选中的文件会作为任务线索交给助手；如需它查看内容，请在消息中说明。

## 发送第一条消息

可以先发一个便于检查的请求，例如「说明这个项目有哪些主要文件夹」。默认按 Enter 发送，Shift + Enter 换行。

回复和操作记录会陆续出现。如果助手请求权限或需要补充信息，输入框上方会出现卡片。读清楚卡片再回应。是否需要逐次确认，取决于当前权限设置。

任务进行时可以取消；已经修改的文件不会因此恢复。

## 没有找到助手

打开「设置 → Agent 管理」，点「自动检测 Agent」。选中助手查看结果，按提示安装、登录或检查版本，然后重试连接。详细步骤见[连接 AI 助手](agents.md)。
