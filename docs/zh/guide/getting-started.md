# 安装与上手

这篇文档带你走完第一次使用：装好一个 AI 助手、装上 Zeta、打开项目、发出第一条消息。

## 开始之前：先装一个 AI 助手

Zeta 本身不包含 AI 模型，也没有账号系统。它是一个外壳，驱动的是你电脑上已经装好的命令行 AI 编码助手。所以第一步不是下载 Zeta，而是准备好下面三个里的至少一个：

| 助手 | 出品方 | 安装 | 登录 |
| --- | --- | --- | --- |
| Codex | OpenAI | 见 [Codex CLI](https://github.com/openai/codex) | 终端执行 `codex login` |
| Claude Code | Anthropic | `npm install -g @anthropic-ai/claude-code` | 终端执行 `claude auth login` |
| Grok | xAI | 见 xAI 官方说明 | 终端执行 `grok login` |

装完之后，请在终端里先跟它聊一句，确认它自己能正常回话。Zeta 只是把它接进图形界面——命令行里跑不通的事，在 Zeta 里同样跑不通。

已知的版本要求：

- Codex 需要 0.142.5 或更高。低于这个版本，Zeta 会在界面上标注「版本过旧」并停止发送消息。
- Grok 需要 0.2.119 或更高。更早的版本无法同时处理多个会话，同时开几个会话时状态会串。
- Claude Code 建议使用 2.1.22x 或更高，这是当前验证过的版本区间。

## 系统要求

- macOS 10.15 及以上，Intel 与 Apple 芯片都支持
- Windows 10 或 11，64 位
- Linux 64 位，需要 GTK 3、fontconfig、util-linux 和 xz 的运行库（deb 与 rpm 包会自动声明这些依赖）

## 下载与安装

到 [Releases 页面](https://github.com/linpeilie/zeta/releases) 下载对应平台的包。每个包都附带同名的 `.sha256` 文件，可以用来校验下载是否完整。

| 平台 | 安装版 | 免安装版 |
| --- | --- | --- |
| macOS（通用，兼容 Intel 与 Apple 芯片） | `zeta-<版本>-macos-universal.dmg` | `zeta-<版本>-macos-universal.zip` |
| macOS（仅 Apple 芯片 / 仅 Intel） | `...-macos-arm64.dmg` / `...-macos-x86_64.dmg` | 同名 `.zip` |
| Windows 64 位 | `zeta-<版本>-windows-x86_64-setup.exe` | `zeta-<版本>-windows-x86_64.zip` |
| Linux 64 位 | `.deb` / `.rpm` / `.AppImage` | `zeta-<版本>-linux-x86_64.tar.gz` |

如果不确定选哪个 macOS 包，选 universal。

### 首次打开会被系统拦住

安装包目前没有做代码签名，所以第一次打开时操作系统会警告。这是预期内的，处理一次之后就不会再提示：

- **macOS**：提示「无法打开，因为无法验证开发者」时，在访达里右键点击 Zeta，选「打开」，在弹窗里再点一次「打开」。也可以到「系统设置 → 隐私与安全性」里点「仍要打开」。
- **Windows**：SmartScreen 弹出蓝色窗口时，点「更多信息」，再点「仍要运行」。
- **Linux**：用 `.deb` 或 `.rpm` 装完后如果应用菜单里没出现，刷新一下菜单，或直接在终端运行 `zeta`。用 tar.gz 的话，解压后运行目录里的 `zeta` 就行。

## 第一次启动

启动后你会看到欢迎页。Zeta 会在后台扫描你电脑上装了哪些 AI 助手，扫描结果显示在「已安装 Provider」区域，每个助手后面跟着一个状态：

- **可用**：装好了，也登录了，可以直接用。
- **需登录**：找得到程序，但还没登录。回终端执行对应的登录命令。
- **未检测到**：Zeta 没找到这个程序。多数情况是它不在系统的 PATH 里。
- **异常**：找到了但启动不起来，或者版本对不上。

如果一个都没检测到，先别急着重装。打开「设置 → Agent 管理」，那里会逐项显示 Zeta 在哪一步卡住了：找可执行文件、读版本号、查登录状态、还是建立连接。详见[连接 AI 助手](agents.md)。

## 打开一个项目

在欢迎页点「打开项目文件夹」，选一个本地代码目录。也可以用标题栏的「文件 → 打开项目」。

选好之后，界面变成三栏：左边是项目和会话列表，中间是对话区，右边是这个项目的文件树。

文件树是按需加载的——只有你展开某个目录时，Zeta 才去读那一层，所以打开大仓库不会卡住。下面这些目录会被跳过，避免刷屏：`.dart_tool`、`.git`、`.idea`、`.vscode`、`build`、`node_modules`。

## 发出第一条消息

在中间的输入框里写下你想做的事，比如「解释一下这个项目的目录结构」，然后按 Enter 发送。

接下来会发生什么：

1. Zeta 启动你选的那个 AI 助手，把项目目录告诉它。
2. 助手开始工作。它说的话、它的思考过程、它调用的每个工具，都按时间顺序出现在中间那条时间线上。
3. 如果它想执行命令、修改文件或者访问网络，会在输入框上方弹出一张审批卡片，等你点「允许」或「拒绝」。**Zeta 不会替你自动同意任何一项。**
4. 这一回合结束后，如果它改了文件，时间线上会出现「本回合改动」，点开能看到具体改了哪几行。

想让它先给方案再动手，就在输入框里打一个 `/`，选择 `Plan`。它会先产出一份计划，你读完确认后再执行。详见[审批、提问与计划](approvals.md)。
