# 通知与提醒

AI 干活的时候你多半在做别的事。任务跑完了、或者它卡在某个需要你点头的地方，Zeta 会用系统通知叫你。

## 什么时候会通知你

Zeta 只在**你没有正在看那个会话**时发通知。判断标准是三个条件同时成立：

1. Zeta 窗口处于焦点状态
2. 当前显示的是对话工作台（不是设置页或使用统计页）
3. 当前打开的正是产生事件的那个会话

三条全中，Zeta 认为你就在盯着它，不打扰。只要有一条不满足，就发通知。

## 会通知哪些事

分两类，可以在设置里分别开关。

**任务结束**

- 任务已完成
- 任务执行失败
- 任务已中断

**需要确认**

- 需要确认权限
- 需要回答问题
- 需要确认计划
- 计划可以执行

## 通知长什么样

标题只写类别，比如「任务已完成」或「需要确认权限」。正文只写项目目录名和「Agent 会话」。

通知里**不会**出现你的提示词、AI 的回复、命令内容、完整路径、问题原文或错误详情。这是有意的：系统通知会进入操作系统的通知中心，那不是放这些东西的地方。想知道具体发生了什么，点通知回到会话里看。

点通知会把 Zeta 带到前台，并打开对应的会话。如果那个会话已经被删除或者不在当前项目列表里，Zeta 会告诉你打不开，而不是静默失败。

## 任务栏和 Dock

除了系统通知，还有更轻的提醒方式：

- **Windows**：任务栏图标闪烁，并显示未读数
- **macOS**：Dock 图标上显示角标
- **Linux**：取决于桌面环境，通常是窗口的紧急状态提示

回到对应的会话后，这些标记会自动清掉。

## 开关在哪

「设置 → 常规 → 通知」下有三个开关：

| 开关 | 作用 |
| --- | --- |
| 系统通知 | 总开关。关掉之后下面两个都不生效。 |
| 任务结束 | 任务完成、失败或中断时提醒。 |
| 需要确认 | 权限、提问、计划审批或执行确认在等你时提醒。 |

## 收不到通知

先确认操作系统层面给了权限：

- **macOS**：系统设置 → 通知 → Zeta
- **Windows**：设置 → 系统 → 通知
- **Linux**：取决于桌面环境的通知服务是否在运行

再确认不是被上面那条「你正在看」的规则挡掉的。更多情况见[故障排查](troubleshooting.md#桌面通知)。
