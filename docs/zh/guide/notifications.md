# 通知与提醒

离开当前会话后，Zeta 可以在任务结束或需要回应时发出桌面通知。

## 提醒哪些事

- 任务完成、失败或被中断。
- 助手在等待操作许可、问题答案或计划确认。
- 计划已准备好，等待执行。

如果你正在 Zeta 的对话页查看这条会话，就不会重复提醒。切到其他应用、另一条会话、设置页或统计页时，可收到提醒。是否实际送达还取决于系统通知设置。

## 查看详情

通知只写事件类别和简短项目名称。点击通知会打开对应会话，查看具体内容。会话已删除或无法找到时，会提示无法打开。

通知不会展示消息正文、命令、完整路径或错误详情。

## 任务栏提醒

Windows 的任务栏、Mac 的 Dock，以及部分 Linux 桌面环境也会显示闪烁、角标或其他提醒。回到对应会话后，已读标记会清除；具体样式取决于系统。

## 调整开关

打开「设置 → 常规 → 通知」：

| 开关 | 作用 |
| --- | --- |
| 系统通知 | 开启或关闭全部系统通知 |
| 任务结束 | 控制完成、失败和中断提醒 |
| 需要确认 | 控制等待回应和计划执行提醒 |

没有收到通知时，检查上述开关、系统对 Zeta 的通知权限，以及勿扰模式。更多说明见[故障排查](troubleshooting.md#通知)。
