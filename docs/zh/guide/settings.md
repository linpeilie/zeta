# 设置

点击标题栏的齿轮按钮打开设置。左侧分为常规、外观和 Agent 管理。

## 消息发送

| 选择 | 发送 | 换行 |
| --- | --- | --- |
| Enter 发送（默认） | Enter | Shift + Enter |
| Cmd + Enter 发送（Mac） | Cmd + Enter | Enter |
| Ctrl + Enter 发送（Windows / Linux） | Ctrl + Enter | Enter |

经常输入多行内容时，可以选择后两种方式。

## 通知

「系统通知」是总开关；「任务结束」和「需要确认」分别控制两类提醒。系统本身也需要允许 Zeta 发送通知。详见[通知与提醒](notifications.md)。

## 界面语言

可选 English 或简体中文，保存后重启 Zeta 生效。已有对话、模型名称和文件名不会被翻译。

首次安装时，系统首选语言为简体中文时使用中文，繁体中文和其他语言使用英语；此前已有的安装保留中文设置。

## 主题与字体

主题可选跟随系统、浅色或深色。

界面字体用于普通文字，代码字体用于代码和命令。两者都默认使用系统字体，也可以从本机已安装的字体中选择。

界面字号可在 10–20 之间调整，代码字号可在 10–24 之间调整，改动立即生效。所选字体不能使用时，会退回默认字体并提示。
