# 设置

标题栏右侧的齿轮图标打开设置页。左边是分区导航，右边是内容。

设置分三个区：常规、外观、Agent 管理。Agent 管理单独成篇，见[连接 AI 助手](agents.md#agent-管理页)。

## 常规

### 消息发送

**发送快捷键**——决定输入框里按什么键发送消息：

| 选项 | 发送 | 换行 |
| --- | --- | --- |
| Enter 发送（默认） | Enter | Shift + Enter |
| Cmd + Enter 发送（macOS） | Cmd + Enter | Enter |
| Ctrl + Enter 发送（Windows / Linux） | Ctrl + Enter | Enter |

写多行提示词比较多的话，第二种更顺手。

### 通知

三个开关，控制什么时候用系统通知打扰你：

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| 系统通知 | 开 | 总开关。关掉后下面两个不生效。 |
| 任务结束 | 开 | 任务完成、失败或中断时提醒。 |
| 需要确认 | 开 | 权限、提问、计划审批或执行确认在等你时提醒。 |

通知只在你没有正在看那个会话时才发，具体判断规则见[通知与提醒](notifications.md)。

### 界面语言

在 English 和简体中文之间切换。**保存后需要重启应用才会生效**，界面上会标注这一点。

第一次启动时，Zeta 会跟随你的系统语言。

## 外观

### 主题

| 选项 | 说明 |
| --- | --- |
| 跟随系统 | 使用系统当前的浅色 / 深色偏好，系统切换时跟着变。 |
| 浅色 | 浅底、低对比度边框、蔚蓝强调色。 |
| 深色 | 深底、高对比度面板、明亮强调色。 |

### 字体

界面字体和代码字体分开设置，各自可以选字型和字号。

**界面字体**用于普通界面文本和 Markdown 正文。默认跟随系统字体。也可以从你电脑上已装的字体里挑一个——列表支持搜索。

**代码字体**用于代码块、命令、差异视图和工具输出。默认跟随系统等宽字体。也可以从本机已装的等宽字体里挑一个。

**字号**分别可调：

| 项目 | 范围 |
| --- | --- |
| 界面字号 | 10–20 px |
| 代码字号 | 10–24 px |

用左右两侧的减号 / 加号按钮调整，改动立刻生效。

如果你选的字体后来在系统里被卸载了，Zeta 会提示「无法加载所选字体」并回退到默认字体，不会让界面变成空白。

## 设置存在哪

所有设置写在 Zeta 数据目录下的 `config/` 里，是明文 JSON：

- `appearance.json`——主题、字体、字号
- `general.json`——发送快捷键、通知开关、界面语言
- `providers.json`——每个 AI 助手的启用状态、可执行文件路径、选中的模型和权限模式

删掉其中任何一个，重启后会以默认值重建。具体路径见[数据与隐私](data-and-privacy.md)。
