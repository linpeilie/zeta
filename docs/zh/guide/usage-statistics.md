# 使用统计

标题栏的统计按钮打开这个页面。它回答几个具体问题：这段时间我调用了多少次、多少次失败了、烧了多少 Token、哪个项目最费、套餐额度还剩多少。

## 数据从哪来

Zeta 不做估算，也不自己计费。页面上的每个数字都来自两个来源：

1. **各个助手在你本机留下的历史记录**——Codex 在 `~/.codex`、Grok 在 `~/.grok`、Claude Code 在它自己的目录里。Zeta 扫描这些文件，汇总成统计。
2. **助手主动报告的额度信息**——套餐名称、用量窗口、重置时间。

因为读的是助手自己的历史，所以统计**包括你在终端里直接使用它们产生的调用**，不只是通过 Zeta 发起的。

助手没有提供的东西，Zeta 不会补。比如某个助手不报告 Token，页面上就显示「不支持」，而不是给一个估算值。

## 筛选

页面顶部有三个筛选器：

- **时间范围**：当天、最近 7 天、最近 30 天、最近 90 天、本月、上个月，或者自定义起止日期。
- **Agent**：只看某一个助手，或者全部。
- **模型**：只看某一个模型，或者全部。

右上角显示最后更新时间，旁边是刷新按钮。

## 概览

顶部四个数字：

- **调用次数**——这段时间的总调用数，并和上一个同样长度的时间段对比。
- **成功率**
- **Token 使用量**——Token 是模型计费和计量的单位，大致对应一小段文字。这里显示总量，下面按输入 / 输出 / 推理拆开。
- **平均响应时间**——从发出请求到收到第一个字的时间。

### 成功率是怎么算的

- 一个**回合**算一次调用。
- 分母只包含已经结束的调用：完成、失败、已取消。**正在运行和状态未知的不计入分母。**
- 分子是「完成」。「失败」和「已取消」都算不成功。

如果这个口径和你在别处看到的数字对不上，多半就是分母的差别。

### 平均响应时间的样本数

只有助手明确报告了「首字响应时间」的调用才会被计入，缺失的样本不做近似。页面上会标明有效样本数——如果样本数很少，这个平均值参考价值有限。

## 趋势图

中间是趋势图，横轴的粒度会根据你选的时间范围自动调整（选一天按小时，选 90 天按天）。可以切换看哪个指标：调用次数、成功率、Token 消耗、平均响应时间、任务耗时。

## 详情

下半部分是四个标签页。

**Agent 统计**——按助手汇总调用次数、成功率、Token、失败数和平均耗时。

**模型统计**——每个模型消耗了多少 Token，占总量的百分比。Token 按总量、输入、缓存输入、输出、推理拆分。

**项目列表**——按项目汇总，显示最近使用时间。点一个项目可以把整个页面聚焦到它。

**任务列表**——逐条列出每次调用，分页显示。点一条打开任务详情：

- 项目名称和完整路径
- 来源（这次调用是从哪个客户端发起的）
- 开始时间、执行时长、首次响应时间
- Token 明细：总量、输入、缓存、输出、推理
- 状态；失败时还会显示**错误分类**（账号异常 / 运行时异常 / 网络错误 / 超时 / 用户取消 / 其他）、具体原因，以及一条**下一步建议**

任务列表**只展示统计元数据**，不包含你的提示词、AI 的回复或工具输出。这些内容 Zeta 根本没有存下来（见[数据与隐私](data-and-privacy.md)）。

## 套餐额度

左侧栏底部和统计页上都有一块额度面板，显示当前助手的套餐和剩余额度。

它只展示助手实际返回的字段：套餐类型、用量窗口的百分比、重置时间，以及可选的余额。Zeta **不推算**绝对 Token 总额度，也不猜测助手没提供的到期日。

不同助手报告的粒度不一样。以 Claude Code 为例，能看到五小时窗口和周窗口的用量，以及可选的补充额度；周窗口还会区分不同模型。这些细项需要打开「额度详情增强」开关才会读取，详见[连接 AI 助手](agents.md#claude-code-的额度详情开关)。

额度读不出来时（没登录、网络不通、助手没提供这个接口），面板会保留能读到的部分，其余显示「暂时无法读取」，而不是显示成 0。

## 部分数据读不出来

统计依赖扫描本地历史文件，偶尔会有读不动的情况。Zeta 的处理方式是**尽量展示能读的部分**，并在页面上说明缺了什么：

- 某个会话目录没能完整枚举——已展示能读到的数据
- 某几个会话文件读取失败——已展示其余数据
- 某几行历史记录损坏——已跳过并继续统计

这些提示不影响其他数字的正确性。

## 统计索引

为了不用每次都重新扫描全部历史，Zeta 会把汇总结果缓存成一个索引文件。这个文件随时可以删除，删了下次打开会重新扫描，只是慢一点。

索引里存了什么、没存什么，见[数据与隐私](data-and-privacy.md#统计索引里有什么)。
