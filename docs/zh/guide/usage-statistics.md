# 使用统计

点击标题栏的统计按钮，查看调用次数、成功率、用量和响应速度。

## 数字表示什么

| 指标 | 含义 |
| --- | --- |
| 调用次数 | 你发出一次请求，助手处理这次任务，计为一次 |
| 成功率 | 已结束的任务中，正常完成的比例；失败和取消也计入总数 |
| Token 使用量 | 助手提供的文字计量单位，约对应一小段文字；不是字数或金额 |
| 平均响应时间 | 从发出请求到收到最初回复的平均时间，只计入有记录的任务 |

正在运行和状态未知的任务不计入成功率。有些任务没有响应时间记录，页面会显示有效样本数。

统计来自助手在本机保存的历史，所以也可能包含你在终端中使用助手的任务。助手未提供的数据会显示缺失或不支持，不补成估算值。

## 筛选与详情

顶部可选择时间范围、助手和模型。项目列表可以进一步筛选某个项目，刷新按钮用于重新读取数据。

趋势图展示选定时间内的变化。下方可按助手、模型、项目查看汇总，也可以打开任务列表，查看某次任务的时间、模型、用量和结果。

任务详情不包含对话正文或工具输出。需要查看这些内容时，回到对应会话。

## 套餐额度

额度面板显示助手提供的套餐、已用比例和重置时间。这些信息可能来自在线查询，不等同于本机历史统计。

Claude Code 的详细用量需要启用[额度详情增强](agents.md#claude-code-的额度详情开关)。没有读到的额度不能理解为零，也不能理解为无限可用。

Zeta 不计算账单金额。实际收费和剩余额度以服务商的账单或账号页面为准。

## 数据不完整

历史记录缺失、损坏、未能读取，或筛选范围不同，都可能让数字与其他工具不一致。出现「部分数据不可用」时，当前结果只包含可读取的部分，不能当作完整总量。

先检查筛选条件，再刷新。需要清理统计缓存时，见[数据与隐私](data-and-privacy.md#清理与重置)。
