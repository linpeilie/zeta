# 界面导览

Zeta 只有一个窗口，界面结构从头到尾不变：标题栏 + 三栏工作台。这篇文档说明每个区域能做什么。

## 标题栏

窗口顶部是 Zeta 自绘的标题栏，从左到右：

- **菜单**：「文件 → 打开项目」用来添加一个本地目录，「文件 → 退出」关闭应用。
- **左栏开关**：折叠或展开左侧的项目栏。
- **返回主界面**：从设置页或使用统计页回到对话工作台。
- **使用统计**：打开统计页，看调用次数、Token 消耗和套餐额度。
- **设置**：打开设置页。
- **右栏开关**：折叠或展开右侧的文件栏。这个按钮只在对话工作台可用；在设置页和统计页里它是灰的。
- **窗口按钮**：最小化、最大化 / 还原、关闭。

左右两栏的显示状态、宽度和展开情况会被记住，下次启动照原样恢复。

## 欢迎页

没有打开任何项目时，中间显示欢迎页，上面有三块内容：

- **打开项目文件夹**：选择一个本地代码目录。
- **近期会话**：跨项目的最近对话，点一条直接回到那个会话。
- **已安装 Provider**：Zeta 在你电脑上检测到的 AI 助手，每个后面标着状态（可用 / 需登录 / 未检测到 / 异常 / 检测中）。检测在后台进行，第一次启动时会先显示「正在检测」。

## 左栏：项目与会话

左栏是一张卡片，从上到下分三部分。

### 项目列表

每一行是一个你打开过的本地目录，按最近使用排序。点一行切换到那个项目。

项目行上有一个「新建会话」按钮。旁边的更多菜单里可以：

- 刷新会话列表
- 在系统文件管理器里打开这个目录（macOS 上是访达，Windows 上是资源管理器）
- 从列表移除这个项目（不会删除磁盘上的任何文件）

如果某个项目下有正在执行的任务，项目行上会有运行中的标记。

### 会话列表

展开一个项目，下面列出这个项目的历史会话。点一条进去继续聊，历史消息会重新载入。

在会话上可以做这些操作，具体哪些可用取决于你用的是哪个 AI 助手（见[连接 AI 助手](agents.md)的能力对照表）：

- **重命名**：改会话标题。
- **归档 / 取消归档**：把不再关注的会话收起来。
- **分叉**：从这条会话复制出一条新的，原会话保留。
- **从 Zeta 列表移除**：只删掉 Zeta 这边的记录，AI 助手自己的历史文件不动。
- **删除会话**：彻底删除，不可撤销。

### Agent 统计（折叠）

卡片底部有一小块只读统计，默认折叠，显示当前 AI 助手的套餐、最短周期的剩余额度和今日 Token 消耗。展开可以看更详细的额度窗口。完整的统计在[使用统计](usage-statistics.md)页里。

## 中栏：对话

这是主要工作区。上半部分是时间线，下半部分是输入框。

时间线里按时间顺序排列这一次对话的全部内容：你说的话、AI 的回复、它的思考过程、它调用的每个工具、它这一回合改动的文件。详见[对话与时间线](conversations.md)。

对话区顶部的工具条上有：

- **项目名**和会话标题（点标题可以重命名）
- **上下文**：打开一个侧面板，显示这个会话的基本信息——会话名称、ID、消息数、使用的助手、上下文窗口上限、Token 用量（输入 / 输出 / 缓存）、创建时间和最后活跃时间。面板里还能切换到「原始消息」视图，查看未经加工的往来数据，可以选中复制。
- **更多**：重命名、分叉、归档等会话操作。

输入框上方是审批区。需要你确认权限、回答问题或审批计划时，卡片固定出现在这里，不会被后续消息挤走。

## 右栏：文件

右栏是当前项目的文件树。

它是按需加载的：只有展开某个目录时才去读那一层，所以打开很大的仓库也不会卡。以下目录会被自动跳过，这个列表目前是固定的：

```
.dart_tool   .git   .idea   .vscode   build   node_modules
```

点一个文件会选中它，选中的文件路径会作为上下文交给 AI。**Zeta 不会自动把文件内容读出来发过去**——要不要读、读多少，由 AI 自己决定，它读了什么你能在时间线上看到。

哪些目录展开着、选中了哪个文件，重启后会恢复。

## 窄窗口

把窗口拉窄时，左右两栏会从固定分栏改成浮层：点开覆盖在对话区上方，点别处收起。对话区始终保持完整可用。

## 主题与字号

界面有深浅两套主题，跟随系统或手动指定。界面字体和代码字体可以分别设置字型和字号。详见[设置](settings.md)。
