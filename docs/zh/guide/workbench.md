# 界面导览

打开项目后，Zeta 分为左、中、右三个区域。

## 左边：项目与对话

点击项目名称切换项目，展开后可查看它的历史对话。点击一条对话继续阅读或发送消息。

项目旁的按钮用于新建对话。更多菜单提供刷新、在系统文件管理器中打开目录、从列表移除项目等操作。移除项目不会删除项目文件。

对话菜单可能提供重命名、归档、创建分支或删除。可用选项取决于所用助手。**删除会话**和**从 Zeta 列表移除**影响不同，请阅读确认提示：后者保留助手自己的历史记录。

左栏底部可以展开使用量摘要，查看所选助手的套餐和今日用量。

## 中间：对话

上方按时间顺序显示你的消息、助手回复和操作记录，下方是输入框。等待确认或回答的问题固定在输入框上方。

对话顶部显示项目和会话名称。「上下文」可以查看这次对话的基本信息、用量，以及用于排查问题的详细记录。分享这些记录前请检查是否包含私人内容。

具体操作见[对话与时间线](conversations.md)。

## 右边：文件

右栏列出当前项目的文件。点击文件夹展开，点击文件选中它。选中只告诉助手你关注哪个文件；需要它阅读时，在消息中提出要求。

Zeta 不提供文件编辑器。助手对文件所做的修改可以在对话里查看，显示范围取决于助手提供的记录。

一些工具文件夹不会出现在列表中，例如 `.git`、`.dart_tool`、`.idea`、`.vscode`、`build` 和 `node_modules`。

## 顶部按钮

顶部菜单用于打开项目和退出应用。其他按钮用于回到对话、打开使用统计或设置，以及收起左右两栏。设置页和统计页不提供右侧文件栏。

拖动分栏边缘可以调整宽度。窗口较窄时，侧栏会覆盖在对话上方，收起后继续看对话。

项目列表、分栏宽度和部分展开状态会保存。重新打开 Zeta 时进入上次使用的项目，不会自动打开上次的对话；点击通知仍会打开对应会话。切到设置、统计页或另一条对话再回来，草稿和阅读位置会保留；退出应用后，未发送的草稿不保证保留。

字体、字号和明暗主题可在[设置](settings.md)中调整。
