# 产品需求

中文 ｜ [English](../../en/product/product_requirements.md)

Zeta 为使用本机 AI 编码助手的人提供桌面工作界面。用户能在多个本地项目间切换，查看助手的回复和操作，并在需要时回应。

## 主要需求

| 用户需要 | 可观察的结果 |
| --- | --- |
| 找到项目和之前的对话 | 打开本地文件夹后可新建或继续支持恢复的历史对话 |
| 看懂助手正在做什么 | 回复、操作记录、已报告的文件改动和任务状态按时间显示 |
| 控制任务 | 可取消任务、选择权限，并在助手请求时确认或拒绝 |
| 先检查方案 | 可先要求计划、补充要求，再决定是否执行；接受计划不扩大权限 |
| 暂时处理别的事 | 切换设置或统计页后仍保留对话、草稿和阅读位置 |
| 及时回应 | 离开会话后可收到完成或待确认提醒，点击返回该会话 |
| 了解使用量 | 可按时间、助手、模型和项目查看已有记录；缺失数据明确说明 |
| 调整阅读体验 | 可选择明暗主题、字体、字号和中英文界面 |

## 支持范围

当前连接 Codex、Grok 和 Claude Code。不同助手提供的功能不同；未提供的操作不显示入口。详细对照只在[助手指南](../guide/agents.md)维护。

Zeta 不包含模型、代码编辑器、云端对话同步或手机应用。用户需要自行准备助手和账号。文件修改由助手执行，取消任务和创建对话分支不会撤销已修改的文件。

## 数据与恢复

Zeta 保存设置、项目列表和使用统计等本地记录。恢复依赖项目目录及助手历史仍然存在，不能保证恢复已经删除的数据。未发送草稿只用于本次运行，不承诺退出后恢复。

本地运行不代表离线处理：助手可能把内容发往模型服务。说明中必须区分 Zeta 保存的资料、助手保存的历史，以及助手向外发送的内容。详见[数据与隐私](../guide/data-and-privacy.md)。

## 验收重点

- 在支持的系统上完成打开项目、发送、回应请求、取消和继续历史对话。
- 多项目和后台任务的状态显示正确，切换页面不影响正在执行的任务。
- 权限选项的说明与实际影响一致，不以接受计划代替操作授权。
- 大字号和窄窗口可读，关键操作可通过键盘完成。
- 出错时说明用户可以采取的下一步，缺失数据不显示成成功或零用量。

产品需求描述目标和验收条件，不代替已执行的测试证据。
