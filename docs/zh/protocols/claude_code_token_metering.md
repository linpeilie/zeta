# Claude Code 用量口径

本文面向适配与统计开发者。当前字段与取样基线以 [stream-json 协议](claude_code_stream_json_protocol.md)为准；不以本地研究副本或字符估算作为协议事实。

## 三类数据

| 数据 | 当前依据 | 使用限制 |
| --- | --- | --- |
| 实时回合用量 | `result.usage` | 本回合绝对值，不当作 thread 累计值再差分 |
| 本地历史用量 | assistant 消息的 `message.id` 和 `usage` | 同 id 最后值覆盖，不同 id 汇总，避免重复计数 |
| 套餐额度 | 单独的用量查询 | 展示服务返回的窗口和比例，不从本地 Token 总量推算余额 |

实时用量映射的总量包含输入、输出、缓存创建与缓存读取。历史统计也须保留缓存部分，不能只加 input 与 output。缺字段与明确的零值需要区分。

## 实现边界

- 字段解析、去重和归一化在 Claude 插件 data 层，宿主只消费中立 `AgentTokenUsage` 和统计模型。
- 回合累计用量不等于上下文窗口占用；不能据累计总量决定是否压缩。
- 不用“字符数除以四”等估算补齐助手未提供的统计值。
- 不把 usage 中的 `service_tier` 推断为当前 Fast 设置；配置证据按协议文档规定读取。
- 用量索引不保存提示词、回复、工具输出、原始错误或会话文件路径。

## 验证

修改计量时覆盖重复 message id、缺失 usage、零值、缓存读取/创建、多个消息求和及 live/history 一致性。Provider 测试和实际字段记录是证据，不从 UI 显示反推私有协议。

旧计量研究涉及未实施的本地估算算法和不可复现的个人源码路径，已从现行文档移除，可在 Git 历史查阅。
