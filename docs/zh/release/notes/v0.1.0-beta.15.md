# v0.1.0-beta.15

这次 beta 重点改善对话阅读、复制与切换体验：长文件路径不再挤压代码正文，切换对话时保留未发送内容和阅读位置，点击输入卡片空白处也能开始输入。

### 📖 阅读与复制

- 修复代码块带长文件路径时正文被挤压、只显示少量字符的问题；文件名和行号显示在顶部，悬停可查看完整引用。
- 可以跨消息选择对话文字，选中高亮与文字位置对齐；代码块横向滚动时，拖选文字更稳定。
- 修复 macOS 对话文字复制的快捷键与菜单衔接，选中文字后可用 ⌘C 或“复制”菜单复制。

### 📂 项目与对话

- 重新打开 Zeta 时进入上次使用的项目，不再自动打开上次的对话。点击通知仍会打开对应会话。
- 在项目里切换对话时，每条对话未发送的草稿和阅读位置会保留到退出应用前。
- 快速切回上一条对话时，当前会话保持一致；删除正在查看的对话后返回项目首页。
- 从对话打开使用统计后可正常停留和返回，支持键盘返回及放大文字；等待新对话创建时打开设置，设置页不会被自动关闭。
- 设置中取消离开后，通知不会在后台切换当前会话。大小写不同的项目目录也能独立打开。

### ✍️ 输入与键盘操作

- 点击输入卡片空白处也会开始输入，不必精确点到文字上。
- 发送和停止按钮外侧增加一圈同色细环，更容易辨认。
- 对话输入框里的模型、权限和菜单弹出层，现在与输入框使用相同的底色、描边和圆角。
- 用键盘切换对话输入框里的模型和权限时，焦点框样式保持一致；从设置返回后再按 Tab，焦点留在当前对话中。

### 🪟 Windows 通知与安装

- 桌面通知恢复显示 Zeta 图标，方便辨认任务提醒。
- 安装结束页不再提供立即打开选项；安装完成后请从开始菜单启动。
