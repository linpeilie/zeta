# Agent 管理功能需求与详细设计

## 1. 功能概述

### 1.1 页面名称

**Agent 管理**

页面说明：

> 管理本机已安装及当前应用支持的 Agent CLI，查看账号、版本、运行状态、模型能力和本地配置。

### 1.2 功能目标

Agent 管理页面用于统一管理应用支持的不同厂商 Agent CLI，包括：

- 展示应用支持的全部 Agent CLI。
- 自动检测本机已经安装的 Agent CLI。
- 查看 Agent CLI 的安装、账号、版本和运行状态。
- 启用或禁用指定 Agent。
- 测试 Agent 是否可以正常调用。
- 查看 Agent 的模型及能力信息。
- 读取和编辑 Agent 本地配置文件。
- 查看 Agent 运行日志和连接异常原因。

### 1.3 第一阶段功能范围

第一阶段包含：

1. Agent CLI 列表。
2. 已安装状态检测。
3. 自动检测本机 Agent CLI。
4. Agent 基础信息展示。
5. 账号状态展示。
6. 当前版本和最新版本展示。
7. Agent 启用和禁用。
8. Agent 运行状态展示。
9. Agent 详情页面。
10. 模型列表。
11. Agent 配置文件读取、编辑和保存。
12. 测试连接。
13. 查看运行日志。

第一阶段暂不包含：

- 在应用内安装 Agent CLI。
- 在应用内自动升级 Agent CLI。
- 多账号切换。
- 不同 Agent 之间的智能路由。
- Token 和费用统计。
- 项目级 Agent 覆盖配置。
- Agent 自动故障转移。
- Agent 插件市场。

# 2. 核心概念

## 2.1 Agent 定义

Agent 表示当前应用支持的一种 Agent CLI，例如：

- Codex CLI
- Claude Code
- Gemini CLI
- OpenCode
- 自定义 Agent CLI

一个 Agent 由两部分组成：

### AgentDefinition

应用内预置的 Agent 支持定义，包括：

- Agent 名称。
- 厂商名称。
- 官方图标。
- CLI 命令名称。
- 支持的操作系统。
- 支持的通信协议。
- 支持的配置文件格式。
- 配置文件默认路径。
- 账号状态检测方式。
- 版本检测方式。
- 模型列表检测方式。
- 日志读取方式。

### AgentInstallation

当前计算机上的实际安装实例，包括：

- 是否已安装。
- 可执行文件路径。
- 当前版本。
- 账号状态。
- 运行状态。
- 配置文件路径。
- 最近检测时间。
- 最近一次异常。

因此，即使某个 Agent CLI 尚未安装，也可以出现在“全部支持”列表中。

# 3. 页面信息架构

Agent 管理包含两个页面：

```text
Agent 管理列表
    └── Agent 详情
          ├── 基础信息
          ├── 模型
          └── 配置
```

## 3.1 推荐交互形式

推荐使用：

> 列表页 + 独立详情页

不建议第一阶段使用弹窗或行内展开作为完整详情载体。

### 不推荐弹窗的原因

Agent 详情包含：

- 多个标签页。
- 状态诊断。
- 较长的路径信息。
- 模型列表。
- 配置文件代码编辑器。
- 日志查看入口。

弹窗空间不足，容易造成多层滚动，也不适合编辑配置文件。

### 不推荐行内展开的原因

行内展开适合展示少量补充信息，但不适合：

- 模型表格。
- 配置编辑器。
- 连接诊断。
- 长时间停留和编辑。

### 推荐交互

用户点击列表中的任意 Agent 行，进入该 Agent 的独立详情页面。

返回列表时需要保留：

- 当前列表标签。
- 搜索条件。
- 筛选条件。
- 滚动位置。

# 6. Agent 列表分类

页面使用两个一级标签：

```text
已安装
全部支持
```

## 6.1 已安装

展示本机已经检测到的 Agent CLI。

默认进入该标签。

包含：

- 已启用 Agent。
- 已禁用 Agent。
- 登录异常 Agent。
- 当前未运行 Agent。

## 6.2 全部支持

展示应用内置支持的所有 Agent CLI，包括尚未安装的 Agent。

未安装 Agent 的状态显示：

```text
未安装
```

未安装 Agent 不展示：

- 账号状态。
- 当前版本。
- 运行状态。
- 启用开关。

可以提供次要操作：

```text
查看安装说明
```

第一阶段不提供应用内直接安装。

# 7. 列表字段设计

## 7.1 Agent

展示：

- Agent 图标。
- Agent CLI 名称。
- 可选的 CLI 命令名称。

示例：

```text
[图标] Claude Code
       claude
```

## 7.2 厂商

展示厂商名称，例如：

- OpenAI
- Anthropic
- Google
- OpenCode

## 7.3 账号状态

状态包括：

| 状态     | 说明                       |
| -------- | -------------------------- |
| 已登录   | 已检测到有效登录状态       |
| 未登录   | CLI 已安装，但没有登录     |
| 登录失效 | 存在登录信息，但验证失败   |
| 无需登录 | Agent 不需要账号认证       |
| 无法检测 | 当前适配器无法获取账号状态 |
| 检测中   | 正在检测账号状态           |

推荐同时使用图标、颜色和文字，不能只使用颜色。

## 7.4 是否启用

使用开关控件：

```text
启用   [●]
禁用   [○]
```

启用代表当前应用可以调用该 Agent。

禁用不会：

- 卸载 Agent CLI。
- 修改 Agent CLI 自身配置。
- 退出 Agent CLI 账号。

禁用仅表示当前应用不再调用该 Agent。

## 7.5 当前版本

展示本机 CLI 版本，例如：

```text
1.2.3
```

无法获取时显示：

```text
未知
```

路径失效时显示：

```text
不可用
```

## 7.6 最新版本

状态包括：

| 显示     | 说明               |
| -------- | ------------------ |
| 1.2.3    | 已获取最新版本     |
| 检查中   | 正在获取           |
| 未知     | 当前无法获取       |
| 检查失败 | 网络或版本服务异常 |

存在新版本时，在当前版本旁显示：

```text
1.2.1  可更新
```

第一阶段只展示版本信息，不提供自动升级。

可以提供“复制升级命令”作为次级操作，但不是第一阶段必要功能。

## 7.7 运行状态

运行状态描述 Agent 当前是否被应用调用。

| 状态   | 说明                         |
| ------ | ---------------------------- |
| 空闲   | Agent 可用，但当前没有任务   |
| 启动中 | 正在创建 Agent 进程          |
| 运行中 | 正在处理任务                 |
| 停止中 | 正在终止任务或进程           |
| 异常   | 进程或通信异常               |
| 未运行 | 当前没有 Agent 进程          |
| 不可用 | CLI 或账号状态不满足运行条件 |
| 已禁用 | 当前 Agent 已被禁用          |

“未运行”和“不可用”需要区分：

- 未运行：可以运行，只是当前没有运行。
- 不可用：当前无法正常运行。

# 9. 自动检测 Agent

## 9.1 检测范围

点击“自动检测 Agent”后，系统依次检测：

1. 支持的 CLI 命令是否存在。
2. 可执行文件实际路径。
3. 当前 CLI 版本。
4. 账号登录状态。
5. Agent 配置文件。
6. Agent 是否正在运行。
7. Agent 通信能力。
8. 最新版本信息。

## 9.2 检测路径

需要检测：

- 系统 PATH。
- 常见安装目录。
- 用户自定义路径。
- 包管理器安装目录。
- 已保存的 CLI 路径。
- Agent 官方默认安装目录。

## 9.3 检测过程

点击后显示非阻塞状态：

```text
正在检测 Agent CLI，已完成 3/5
```

列表中的对应 Agent 可以逐项进入“检测中”状态。

不需要等待所有 Agent 检测完成后再更新页面。

## 9.4 检测结果

检测完成后显示结果摘要：

```text
检测完成

发现 4 个已安装 Agent
新增发现 1 个
更新状态 2 个
存在异常 1 个
```

推荐以页面顶部提示条或 Toast 展示。

如果存在异常，提供：

```text
查看异常 Agent
```

## 9.5 重复检测

重复检测不会创建重复 Agent。

检测结果根据 Agent 唯一标识和可执行文件路径更新现有记录。

# 13. 详情页快捷操作

右上角提供：

```text
[测试连接] [查看运行日志] [启用 / 禁用]
```

## 13.1 测试连接

点击后执行完整的连接检测。

检测步骤：

1. 检查可执行文件是否存在。
2. 检查当前版本是否可调用。
3. 启动测试进程。
4. 检查账号状态。
5. 建立通信连接。
6. 发送最小测试请求。
7. 验证返回数据格式。
8. 关闭测试进程。

测试过程中按钮显示：

```text
[正在测试…]
```

测试成功：

```text
连接测试成功

CLI 可正常启动
账号认证有效
通信协议正常
响应耗时 286 ms
```

测试失败：

```text
连接测试失败

失败阶段：账号认证
错误原因：当前登录凭证已失效

建议操作：
重新登录 Claude Code 后再次测试。

[复制错误信息] [重新检测]
```

测试结果需要保存：

- 测试时间。
- 测试结果。
- 响应耗时。
- 失败阶段。
- 原始错误摘要。

## 13.2 查看运行日志

支持日志的 Agent 显示按钮。

不支持日志读取时：

- 隐藏按钮；或
- 禁用按钮并显示“当前 Agent 不支持日志读取”。

日志推荐使用独立页面或右侧大抽屉，不使用小弹窗。

日志页面支持：

- 实时日志。
- 日志级别筛选。
- 关键词搜索。
- 自动滚动。
- 暂停刷新。
- 复制日志。
- 导出日志。
- 清空当前视图。

第一阶段至少提供：

- 日志查看。
- 搜索。
- 复制。
- 刷新。

## 13.3 启用或禁用

启用状态使用：

```text
[禁用 Agent]
```

禁用状态使用：

```text
[启用 Agent]
```

禁用操作建议使用次级危险按钮，不使用强烈红色，除非会终止正在运行的任务。

# 15. 基础信息字段

## 15.1 名称

展示 Agent 名称：

```text
Claude Code
```

第一阶段可以只读。

未来如果支持自定义别名，可以增加：

```text
显示名称
工作 Claude
```

## 15.2 厂商

展示厂商名称，只读：

```text
Anthropic
```

## 15.3 Agent CLI

展示 CLI 命令名称，只读：

```text
claude
```

可以提供复制按钮。

## 15.4 账号状态

展示：

- 当前状态。
- 登录账号标识，如果 CLI 支持读取。
- 最后检测时间。
- 重新检测按钮。

示例：

```text
账号状态
已登录

账号
user@example.com

最后检测
2026-07-10 10:32
```

涉及隐私时可以只展示脱敏信息：

```text
u***@example.com
```

## 15.5 可执行命令文件路径

展示和编辑当前 CLI 路径：

```text
C:\Users\User\AppData\Roaming\npm\claude.cmd
```

提供：

```text
[选择文件] [自动检测] [打开所在目录]
```

路径输入框使用等宽字体。

修改路径后需要重新执行基础检测。

路径无效时显示字段级错误：

```text
该文件不存在，或者当前应用没有执行权限。
```

## 15.6 通信协议

展示当前 Agent 适配器使用的协议，例如：

- JSON-RPC。
- JSON Lines。
- Stream JSON。
- ACP。
- MCP。
- 自定义协议。

第一阶段建议只读，由 Agent 适配器定义。

## 15.7 传输方式

展示：

- 标准输入输出。
- HTTP。
- WebSocket。
- 本地 Socket。

示例：

```text
stdin / stdout
```

第一阶段建议只读。

## 15.8 超时时间

允许用户设置连接或请求超时时间。

示例：

```text
60 秒
```

推荐规则：

- 最小值：5 秒。
- 最大值：600 秒。
- 默认值：60 秒。
- 输入非法时不允许保存。

需要明确该超时时间的含义：

> Agent 启动、握手或单次无响应等待的最大时长。

```text
C:\Users\User\claude.exe

建议操作
重新自动检测 Agent，或者手动选择正确的可执行文件。

[自动检测] [选择文件]
```

## 16.3 异常展示原则

不能只显示：

```text
连接失败
```

必须尽量展示：

1. 失败阶段。
2. 用户可理解的异常原因。
3. 原始错误摘要。
4. 建议解决方式。
5. 可直接执行的操作。

异常阶段统一定义为：

- 文件检测。
- CLI 启动。
- 版本检测。
- 账号认证。
- 协议握手。
- 模型读取。
- 配置读取。
- 测试请求。
- 进程退出。

# 17. 模型标签页

## 17.1 页面目标

展示当前 Agent CLI 可以使用的模型，以及模型支持的能力和思考能力。

## 17.2 模型列表字段

建议字段：

| 字段     | 说明                     |
| -------- | ------------------------ |
| 模型名称 | 面向用户展示的名称       |
| 模型标识 | CLI 实际使用的模型 ID    |
| 能力     | 文本、图片、工具、代码等 |
| 思考能力 | 是否支持思考及支持等级   |
| 上下文   | 支持时展示上下文长度     |
| 状态     | 可用、不可用、未知       |

示例：

```text
Claude Sonnet 4.5
claude-sonnet-4-5

能力：
文本、图片、工具调用、代码编辑

思考能力：
支持，可调节

状态：
可用
```

## 17.3 能力标签

能力以标签形式展示：

```text
文本
图片
代码
文件操作
工具调用
终端
流式输出
```

只展示对当前产品有意义的能力，不直接展示厂商所有底层参数。

## 17.4 思考能力

建议统一为以下状态：

| 状态   | 说明                     |
| ------ | ------------------------ |
| 不支持 | 模型没有显式思考模式     |
| 支持   | 支持思考，但无法调节程度 |
| 可调节 | 支持多个思考级别         |
| 未知   | Agent 没有返回该信息     |

如果支持级别，展示：

```text
低
中
高
极高
```

模型自身使用不同命名时，由适配器映射为统一状态。

## 17.5 模型数据来源

模型数据可以来自：

1. Agent CLI 动态查询。
2. Agent 本地配置。
3. 应用内置 Agent 定义。
4. 厂商模型元数据。

优先级建议：

```text
CLI 动态结果
> 当前账号实际可用模型
> 应用内置定义
```

模型列表需要显示数据来源和更新时间：

```text
数据来源：Agent CLI
更新时间：2 分钟前
```

## 17.6 模型异常状态

读取失败时显示：

```text
无法加载模型列表

Agent CLI 未提供模型查询能力，或者当前账号没有完成登录。

[重新加载]
```

如果 Agent 本身不支持读取模型列表：

```text
该 Agent CLI 不支持获取模型列表。
```

# 18. 配置标签页

## 18.1 显示条件

只有 Agent 适配器支持配置文件读取时，才显示“配置”标签。

对于不支持配置读取的 Agent：

- 可以隐藏该标签；或
- 显示只读空状态。

第一阶段推荐隐藏，减少无效页面。

## 18.2 页面布局

```text
配置文件

文件路径
~/.config/claude/settings.json

最后加载
2026-07-10 10:31

[重新加载] [打开所在目录]

┌──────────────────────────────────────────────────────────────┐
│ 1  {                                                        │
│ 2    "permissionMode": "default",                            │
│ 3    "model": "claude-sonnet"                                │
│ 4  }                                                        │
└──────────────────────────────────────────────────────────────┘

配置格式有效                              [取消修改] [保存配置]
```

## 18.3 配置文件信息

展示：

- 配置文件路径。
- 文件格式。
- 文件是否存在。
- 最后修改时间。
- 最后加载时间。
- 当前是否存在未保存修改。

提供：

```text
重新加载
打开所在目录
```

## 18.4 配置编辑器

编辑器至少支持：

- 行号。
- 等宽字体。
- JSON、YAML 或 TOML 语法高亮。
- 查找。
- 基础错误提示。
- 撤销和重做。
- 未保存状态。

根据 Agent 定义确定配置格式。

## 18.5 保存前校验

保存前执行：

1. 配置文件语法校验。
2. 必填字段校验。
3. Agent 自定义配置校验。
4. 文件写入权限校验。

校验失败时：

- 不允许保存。
- 定位到错误行。
- 展示明确错误信息。

示例：

```text
第 12 行配置格式错误

字段 permissionMode 后缺少逗号。
```

## 18.6 保存行为

保存配置时：

1. 重新检查文件是否被外部修改。
2. 创建原配置备份。
3. 写入临时文件。
4. 校验临时文件。
5. 替换原配置文件。
6. 通知 Agent 配置已更新。
7. 必要时提示用户重启 Agent。

保存成功：

```text
配置已保存

新的配置将在下次启动 Agent 时生效。
```

如果需要重启：

```text
配置已保存，但需要重启 Agent 后才能生效。

[稍后重启] [立即重启]
```

第一阶段如果不支持重启，可以只提示：

```text
请重新启动 Agent CLI 以应用新配置。
```

## 18.7 外部修改冲突

如果配置文件在编辑期间被其他程序修改：

```text
配置文件已在外部发生修改

继续保存将覆盖外部修改。

[查看差异] [重新加载] [仍然保存]
```

第一阶段可以暂不提供差异对比，但必须提供：

```text
重新加载
仍然保存
```

## 18.8 离开页面提示

存在未保存修改时，离开页面需要确认：

```text
配置尚未保存

离开后本次修改将丢失。

[继续编辑] [放弃修改]
```

## 18.9 敏感信息

配置文件可能包含 API Key、Token 或其他凭证。

建议：

- 自动识别常见敏感字段。
- 默认遮挡敏感值。
- 提供临时显示按钮。
- 复制完整配置时进行提示。
- 日志中禁止输出敏感配置内容。

常见敏感字段包括：

```text
apiKey
token
secret
password
authorization
accessToken
refreshToken
```

# 21. 状态优先级

一个 Agent 可能同时存在多个状态，列表中的主状态按以下优先级显示：

```text
CLI 不可用
> 账号异常
> 连接异常
> 运行异常
> 正在运行
> 已禁用
> 空闲
> 未运行
```

例如：

- Agent 已禁用，但可执行文件路径已经失效，应优先显示“CLI 不可用”。
- Agent 正在运行，但连接已经中断，应显示“连接异常”。
- Agent 未登录时，即使进程未运行，也应优先显示“需要登录”。

# 22. 保存与刷新规则

## 22.1 自动刷新

以下状态可以自动刷新：

- 运行状态。
- 当前任务状态。
- 进程是否存在。
- 最近一次错误。

推荐刷新间隔：

```text
运行中：2～5 秒
空闲状态：15～30 秒
应用不在前台：暂停或降低频率
```

## 22.2 手动检测

以下信息主要通过手动检测更新：

- Agent 是否安装。
- 可执行文件路径。
- 当前版本。
- 账号状态。
- 配置文件位置。
- 最新版本。

进入详情页时，可以针对当前 Agent 自动执行轻量检测。

# 23. 权限与安全要求

## 23.1 命令执行

所有 Agent 检测命令必须：

- 使用参数数组，不直接拼接 Shell 字符串。
- 设置超时时间。
- 限制输出长度。
- 捕获标准输出和标准错误。
- 防止命令注入。

## 23.2 文件访问

配置文件编辑需要：

- 检查文件权限。
- 使用安全写入。
- 保存前创建备份。
- 避免写入符号链接指向的危险位置。
- 保存失败时保留原文件。

## 23.3 日志脱敏

日志存储和展示前，都需要执行脱敏。

## 23.4 凭证处理

Agent 管理页面只展示账号状态，不直接读取或保存 Agent CLI 的明文凭证。

# 29. 第一阶段验收标准

## Agent 列表

- 能展示全部支持的 Agent CLI。
- 能区分已安装和未安装 Agent。
- 能展示 CLI 名称和厂商名称。
- 能展示账号状态。
- 能展示启用状态。
- 能展示当前版本和最新版本。
- 能展示运行状态。
- 能搜索和筛选 Agent。

## 自动检测

- 能通过 PATH 和常见目录检测 Agent CLI。
- 能识别可执行文件路径。
- 能读取当前版本。
- 能更新账号和运行状态。
- 重复检测不会产生重复数据。
- 检测失败不会阻塞其他 Agent 的检测。

## Agent 详情

- 能从列表进入 Agent 详情。
- 返回时保留列表状态。
- 详情页包含基础信息、模型和配置标签。
- 不支持的标签或功能不会错误展示。

## 基础信息

- 能展示所有指定字段。
- 能修改可执行文件路径和超时时间。
- 能明确展示连接是否正常。
- 连接异常时能展示具体原因和建议操作。

## 模型

- 能展示模型名称、模型标识、能力和思考能力。
- 无法读取模型时有明确空状态。
- 能展示模型数据来源和更新时间。

## 配置

- 能加载配置文件。
- 能编辑并保存配置。
- 保存前进行语法校验。
- 存在未保存修改时，离开页面会提示。
- 文件外部修改时不会静默覆盖。
- 保存失败时不会破坏原配置文件。

## 快捷操作

- 能测试连接。
- 能查看运行日志。
- 能启用或禁用 Agent。
- 操作失败时能展示明确原因。
