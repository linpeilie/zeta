# 使用统计功能需求与详细设计文档

## 1. 功能概述

## 1.1 页面名称

**使用统计**

页面说明：

> 统计和分析本地 Agent CLI 的使用情况，包括调用次数、成功率、性能指标、Token 消耗、项目使用情况以及订阅额度。

---

# 2. 功能目标

使用统计页面用于帮助用户了解：

1. 当前使用了哪些 Agent。
2. 哪些项目正在使用 Agent。
3. Agent 调用是否稳定。
4. Agent 响应速度如何。
5. Token 或资源消耗情况。
6. 当前订阅套餐剩余情况。
7. 哪些任务消耗较高。

---

# 3. 使用场景

## 场景一：查看整体使用情况

用户进入页面，希望快速了解：

- 本周期调用次数。
- 使用最多的 Agent。
- Token 消耗。
- 是否接近额度限制。


## 场景二：分析某个项目使用情况

用户选择：

```
项目：
AI Editor
```

查看：

- 调用次数。
- 使用 Agent。
- Token 消耗。
- 最近任务。


## 场景三：排查 Agent 性能问题

用户发现 Agent 变慢，希望查看：

- 平均响应时间。
- 任务耗时。
- 失败次数。
- 错误原因。


## 场景四：查看套餐额度

用户使用订阅 Agent：

例如：

- Claude Pro。
- ChatGPT Plus。
- GitHub Copilot。
- 企业 Agent。


希望查看：

- 已使用额度。
- 剩余额度。
- 重置时间。
- 到期时间。

# 6. 数据概览区域

页面顶部展示核心指标。

采用轻量数据卡片。

不使用大型 BI 风格卡片。

---

## 6.1 调用次数

字段：

```
调用次数
```

展示：

```
1,280

↑ 12%

相比上一周期
```

定义：

一次用户完整 Agent 请求计为一次调用。

流程：

```
用户提交任务

↓

Agent执行

↓

返回结果
```

---

## 6.2 成功率

展示：

```
成功率

98.6%

失败：
18次
```

计算：

```
成功次数 / 总调用次数
```

失败原因分类：

```
账号异常

CLI异常

网络错误

超时

用户取消
```

---

## 6.3 平均响应时间

展示：

```
平均响应时间

1.8s
```

定义：

```
发送请求

↓

Agent首次返回内容
```

不包含完整任务执行时间。

---

## 6.4 平均任务耗时

展示：

```
平均任务耗时

4m32s
```

定义：

```
任务开始

↓

任务完成
```

包含：

- 文件修改。
- 工具调用。
- 多轮交互。


---

展示：

# 20. 设计原则

1. 页面关注“使用决策”，不是简单日志展示。
2. 所有指标必须支持时间和项目过滤。
3. 不支持统计能力的 Agent 必须优雅降级。
4. Token、套餐、账号信息必须考虑隐私。
5. 数据展示优先解释“为什么”，不仅展示数字。
6. 默认展示最近7天，避免首次进入数据过大。
7. 所有异常必须提供原因和下一步操作。


最终定位：

> 使用统计是 Agent 平台的数据分析中心，帮助用户理解 Agent 的使用频率、性能表现、资源消耗和套餐状态。
